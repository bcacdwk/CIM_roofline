# SRAM ACIM 方法说明与主审入口

## 一、主模式及证据边界

这是一份28 nm外围条件下的参考电路，不是SACIM-03原宏的性能重标。SACIM-03的每个9T1C cell本来就存一个二进制位，128行的电荷耦合列求和是主要实证锚点。原HCA将4列作模拟位权合并、再四位Flash读出；这里绕开HCA，以8个独立权重位平面和名义10位/约8有效位SAR完成近似部分和。SACIM-01的BPBS为跨工艺结构交叉：权重bits分列并行、输入bits串行，ADC后数字移位累加。其1152行/256列、8位SAR和65 nm实现支持方法可行性，但不用于外推28 nm频率。

物理状态131072个binary cell恰表示一份16384Byte逻辑矩阵。8平面×128行×128列不是8个独立服务单元。每次16输出×8平面=128列活动，输入激励通过局部分段缓冲分发；未选输出列要隔离，不能把1024物理列总电容免费挂上同一源。每列128cell的存储位线负载与CMOS-03模型的128cell量级对应。选择隔离和写列掩码是参考设计需实现的资源，非原SACIM-03论文已经认证的功能。

## 二、完整精度次数与符号

8输入位×8输出组=64次阵列求值；各次128个SAR并行产生128码，共64转换批和8192标量转换。一个输出有8输入位×8权重位=64部分和。16条数字通道每批两拍：每输出8权重位合并一拍、按输入位权符号累加一拍，共128拍。捕获与提交另2拍。没有输入位串行造成的额外logical payload，也没有对名义10bit SAR再乘10。

补码系数为(1,2,4,8,16,32,64,-128)，两层位展开严格重建理想整数乘积；脚本用随机和极端符号向量验证代数，不把该测试当模拟精度验证。实际输入为近似部分和。128个二进制乘积之和0…128需129级，8bit码容器足够，但ADC ENOB约8并不保证整数无误。本报告仅沿用共同近似合同，不增设算法误差阈值。

## 三、10/20/50 ns前端预算如何使用

原PDF回查：SACIM-03 p.3 III给100MHz@0.9V，p.5 Table II供电0.9V，p.5 Conclusion却给100MHz@1.2V。这里主动保留冲突，未把0.9V当已闭合PVT证书。10ns是原完整四位宏周期，涵盖reset/evaluation/Flash读出，**不是测得cell或前端单项**。

新参考电路无原HCA/Flash操作，把10ns只当128行电荷前端量级锚点。短预算10ns有前提：binary输入、128活动列、局部缓冲/隔离以及足够驱动能力。参考20ns取2倍，留更精细建立与SAR接口适配；用单极点建立至半LSB的t∝(q+1)ln2可解释4→8bit约9/5=1.8倍，不能将其误写为提取电路RC或精度测量。50ns为5倍宽松工程端点。没有证据保证更长时间能消除静态失配、非线性；需要校准及后续电路验证。

共享JSON的T_I=2/5/10ns不能再加到这三个合并T_F上：API使用read_ns=T_F−T_I=8/15/40ns。该残差为非负工程剩余项，公式仅用于阶段覆盖，不命名为独立实测cell read。ADC仍按共享T_A=10/20/50ns，每颗每样本完整时隙，含逐次比较。没有重复执行原四位Flash，所以不是“原宏完整10ns再加原ADC”。数字节拍和次数另计。无跨向量流水，也无跨输出组模拟保持。

## 四、写侧与已完成DCIM相同标准

普通写的原生状态仍是9T1C内的6T SRAM。数据在8位平面重排，每面16对BL驱动，合计128真实驱动；8局部行译码同选一个输入行/16输出组，1控制域。每批写16个完整INT8，B_R=16Byte；128bit接口之外还需列选择、掩码、数据锁存、驱动和足够电源分发。Q/QB只是同一状态的内部互补节点，不倍增payload。

CMOS-07 28 nm eFlash 2RW 8T、48bit×1kword的455MHz是完整同步时钟锚点；1.54ns是read access，未用。455MHz→2.197802…ns向上取2.2ns。参考/长5/10ns读共享数字节拍对应200/100MHz预算。CMOS-03 TT/1V 6T、128cell/15fF、50FO4≈1ns模型支持数ns级完整同步写及周期末成功定义；不是128bit本宏实测。因此跨48→128bit和8T→9T1C内6T均明确为移植假设，标准与02_sram_dcim一致。

完整T_M从捕获命令、地址、128bit数据，到节点翻转/关WL/恢复以及下个许可计算沿，包含一拍写服务的本地控制；R4替代共享front，Δ_R=T_M，不再额外加2T_D。若用户边界实际多了一层准备/完成握手，应加其占用，而不是把它默认隐藏于这里。ADC不参与普通二进制写verify。无erase、迭代program/verify、refresh或破坏性read restore。下一次计算复位电容已计前端，不因写入再重复收费。

整矩阵1024对齐事务顺序聚合：16384Byte/(1024T_M)，τ与16Byte事务相同。短/参考/长总耗时2252.8/5120/10240ns。稀疏1权重写未合并时应B_R=1Byte。写驱动减为64对对照：同128bit接口可先锁存全部数据，每槽只写64bit，两槽完成同16Byte，τ减半。该对照正好显示接口宽度与真实写并行不同。

## 五、参考手算、敏感性与局限

参考Δ_S=64×20+64×20+128×5+2×5=3210ns，前端1280ns、转换1280ns、重构640ns、边界10ns。ρ=128/3210=0.0398753894GB/s；Δ_R=5ns，τ=16/5=3.2GB/s；ridge=(128/16)(5/3210)=0.0124610592。

short/reference/long Δ_S=1540/3210/7700ns，Δ_R=2.2/5/10ns。两路预算配对后ridge0.0103896…0.0124611较窄，只是配对组织结果，不是统计区间。固定共同reference外围，T_F=10/20/50ns时Δ_S=2570/3210/5130ns，ρ和ridge相对参考+24.9%/0/−37.4%；可见前端不确定性不抵消。独立端点ridge外包络0.0022857…0.0519481仅用于说明混端点的宽度，不将其当同芯片配对实测。

主要待主审问题不是算术，而是条件预算的接受范围：1) 原4b宏结构改为独立列SAR后，高精度前端是否有足够局部缓冲、选通隔离和校准；2) 跨实现128驱动普通写能否维持2.2/5/10ns。本文将其显式资源和预算而非多数null；没有后仿真/硅测认证。普通写与计算互斥，独立两峰值不能保证同时间达到。无具体寿命次数来源，不填伪寿命数值。
