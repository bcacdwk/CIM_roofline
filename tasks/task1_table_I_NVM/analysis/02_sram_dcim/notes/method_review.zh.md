# SRAM DCIM 方法与独立手算

主结构按SDCIM-01 p1Fig1、p2 bit-first、p4Fig10a：单128×128物理bit=K128N16INT8，16 HCA/BFA、16项归约、静态双字线连接。每组八输入bit后才切下一组，8次行组选择和64 MAC槽分列，无新增保持或捕获。0.9V233MHz取4.3ns，参考/长5/10ns为完整MAC预算。

写端128bit口有D6原结构依据；2.2ns锚点为CMOS-07 p2同步连续写组织、p9典型455MHz的向上取整。48bit8T/eFlash到128bit6T属于参考移植，需要128真实BL驱动及供电固定支持。CMOS-03 pp1/3的128cell/15fF模型支持完整写成功终点；readaccess1.54ns和WL半周期均不作为完整写周期。

典型独立手算：64×5+2×5=330ns，输入128Byte，rho=387.8787878788MB/s；16Byte/5ns=tau3200MB/s；RI*=8×5/330=.1212121212。整矩阵2048Byte需128次写，TR=640ns；U*=640/330=1.9393939394=16RI*。23bit输出与原生K128相容，输入1024bit、输出368bit。

主三情景同一原生tile、16项归约/16输出、128驱动固定，时间分别受相容服务窗口控制。原始/有效能力相同，无refresh或破坏恢复。计算/写入共享状态，不能保证独立峰值同时达到。

八原生tile容量组织另列K128N128：已安装128HCA/BFA、活动16、单写域；DS=512×5+10=2570ns，TR1024×5=5120ns，U*=1.9922178988。该容量组织保留原归约，未假造32项同钟。不同N不能仅用rho排名；完整TR/DS根据TableII映射匹配。

脚本检查原生容量与位覆盖、完整周期不重复控制、静态保持生命周期、驱动数量、源哈希、独立算术及生成同步。主要外审是128bit普通写跨实现时序，不能把有条件估算当同芯片配对实测。
