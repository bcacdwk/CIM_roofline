\section{状态模式与证据的分工}
NOR 的非易失状态可以表示二进制位，也可经精调表示连续模拟权重；两者有不同的成功终点。本章选择\textbf{二进制存储加局部数字计算}：读出各 bit 的 0/1 判决，数字逻辑完成乘法、符号处理和累加。一个 INT8 权重由八个逻辑存储 bit 表示，不要求某个 cell 提供 256 个稳定电流值。矩阵共 131072 个逻辑存储 bit；一次输入 $B_S=128$ Byte，完整矩阵更新 $B_R=16384$ Byte，结果为 128 个 24-bit 有符号容器。

\sid{NOR-04} 则是经过阵列改造的 180 nm ESF1 模拟分类器。浮栅电荷改变晶体管阈值和导通电流，输入激励与已调好的权重产生电流贡献，列上求和，差分连接表示正负权重。其第一层采用二电平\emph{输入}，并不意味着其\emph{权重}是普通二进制 Flash。该原型有 101780 个浮栅 cell、784--64--10 网络，输入先串行装入 785-bit 寄存器。论文的亚微秒量级描述网络传播，不是本章 INT8 完整服务间隔；Fig.~14 的振荡与输入电路限制也不能略去。

\sid{NOR-05} 给出 100-cell 调谐实验：平均约 10 次脉冲达到 3\% 调谐误差，35 次达到约 0.3\%。其 Fig.~2 包含全擦初始化、读状态、模型更新和交替擦写；Fig.~3 的 100\,$\mu$s 编程脉冲与 2.5 ms 擦除脉冲是动力学表征条件，不是完整权重调谐时延。\sid{NOR-04} 原型实际采用约 5\% 单 cell 导入目标，后续半选扰动也有影响。两篇同技术线分别支持模拟机制和调谐方法，不能当作独立的二进制写入验证。

本章没有把模拟调谐的 10/35 次脉冲加在厂商页编程时间之后，也没有把普通 binary 页编程终点解释为模拟电流精度。所选数字路径与 binary 更新相容：判决只需满足数字读窗，权重位权和输入补码符号在数字域处理，输入符号位取 $-2^7$。它是一种包含本地 NOR 感测和归约资源的参考宏；库内尚无对应该映射的已制造 NOR DCIM 宏，因此不将本估算标成原型实测。

\section{本地读分片与原生更新域的映射}
主布局保持共享 R0：每轮处理 32 个输入项、16 个输出，八位权重并行、输入逐 bit 展开。实现这一轮需要\textbf{32 个独立读分片，每片 128 个二进制 sense amplifier（SA），共 4096 SA}，以及 16 条 32 项数字归约/累加通道、128 个 24-bit 输出累加寄存器。一个读分片在一轮只选择自己的一个局部字线，不要求普通 NOR 在同一位线上同时辨认 32 个 cell。

按输入索引 $i=0,\ldots,127$ 和输出 $o=0,\ldots,127$ 映射，分片 $s=i\bmod32$ 保存 $i=s,s+32,s+64,s+96$ 四行，每行 128 Byte，因此每片有效容量 512 Byte。读轮的组号 $g=0,\ldots,3$ 使各片选取输入行 $i=s+32g$；输出组 $h=0,\ldots,7$ 选择其中连续 16 个权重，共 128 bit。每个输入 bit 重读这些状态，沿用 R0 的无跨输入位复用、无跨向量流水调度选择；4096 个 SA 的当轮数字输出直接供归约，不配置跨八个输入位持有全部 4096 bit 的独立权重寄存。这里的重复感测来自所选数据通路和调度，不是 NOR 介质要求。

\textbf{独立读分片不等于独立擦除域。} 主布局将相邻八片的 $8\times512=4096$ Byte 放在一个 4 KiB sector，四个 sector 恰好覆盖整矩阵。每片的两张 256 Byte 页，各保存两个完整逻辑输入行；一个 sector 共 16 页，整矩阵共 64 页。该组织需局部字线/位线选择、读偏置缓冲和感测隔离，并让同一 sector 的八片在擦除时共享高压选择及擦除控制。编程时只选一页，其他页受抑制；全宏只有一个 program/erase 控制域和一套活动页缓冲。

\sid{NOR-02} 规定页与 sector 的外显更新粒度，没有规定一个 sector 只能有一个本地读通道。本章把读分段与高压更新域分别设计，\emph{不是声称 W25Q128JV 内部已有这 32 个并行端口}。128-bit 本地数据接口、128-SA 读宽和 256-Byte 内部页算法是三个不同资源；接口宽度不能推导 128 个 cell 同时编程，更不能推出 32 页并行写。

\section{Streaming：完整二进制读与数字归约}
采用共享 API \texttt{dcim\_service} 计算 R0，操作次数为
\[
N_D=N_{\rm rd}=8\times1\times4\times8=256,\qquad
\Delta_S=256(t_{\rm rd}+T_D)+2T_D.
\]
一轮二进制读提供 32$\times$16 个 INT8 权重；随后一拍完成相应输入 bit 的选择乘法、32 项归约、符号处理和 16 个输出的部分和更新。公共 $T_D=2/5/10$ ns 分别取自共享 short/reference/long 情景；$T_I$ 和 ADC 时隙不用于本数字路径。必要读偏置建立、选择和感测都放入完整 $t_{\rm rd}$，不再重复叠加一个“cell read”周期。

\sid{NOR-01} PDF p.~85 Table~57/58、p.~86 Table~59 的随机读周期分别为 100/120/130 ns。100 ns 档针对 512 Mb、$V_{\rm IO}=V_{\rm CC}=2.7$--3.6 V、$-55$ 至 $105\,^{\circ}\mathrm C$；120 ns 档覆盖更多容量与 $125\,^{\circ}\mathrm C$；130 ns 档包含低至 1.65 V 的 I/O 条件。原表分别给出最小允许读周期 $t_{\rm RC}$ 和最大地址到输出延时 $t_{\rm ACC}$，数值一致。这里用它们锚定三档\emph{完整本地二进制读预算}，不是将 $t_{\rm ACC}^{-1}$ 直接称作向量吞吐。

这一步有明确工程桥接：商品的外部 16-bit 接口并不等于本地 bitline 感测宽度，本设计另配置 128-SA 宽的局部感测和 32 组读偏置/选择电路；假定其负载、输出隔离和数字读窗允许 100--130 ns 的完整周期。NOR-01 的原工艺为 65 nm、介质电压并非 0.9 V；28 nm 只指共享数字外围参考。既不凭工艺缩小比例加速 NOR，也不从 SPI 的 50/133 MHz 或连续数据速率推导介质读时间。移植后的宽度与读时间相容性仍是待电路验证的主要条件。

\section{Resident：页编程、sector 擦除和完成终点}
\sid{NOR-02} PDF p.~37 规定 Page Program 向已擦为 FFh 的区域写入 1--256 Byte；命令与数据装入结束后，才启动内部自定时 $t_{\rm PP}$。PDF p.~39 规定 4 KiB Sector Erase 把整个 sector 置为 1；p.~14 定义 BUSY 在操作结束后归零。p.~66 的详细 AC 表给出 $t_{\rm PP}=0.4/3$ ms、$t_{\rm SE}=45/400$ ms（typ/max）。这些是普通 binary 状态的完整内部操作，所需脉冲、内部校验和恢复已由控制器覆盖，不能再套一个未报告的重试倍数或模拟精调循环。

本章采用持续整矩阵任意重写，先逐 sector 完成擦除，再串行装入并提交有效页；四个 sector 的顺序可变，但不能并行借用 32 个更新引擎。每页在本地 128-bit 接口需 $256\times8/128=16$ 拍装入，加准备与完成各一拍，共 $18T_D$；每个擦除命令另计两拍本地控制。页缓存和完成信号处于宏内部，SPI 线缆命令传送在所选局部边界之外。专用高压建立不按低压 $T_D$ 替换，而保留在毫秒量级完整内部块中。

主布局每次擦除支撑 $N_{p/e}=16$ 个有效页。等效页服务与完整矩阵服务分别为
\begin{align*}
\Delta_{R,\rm page}&=18T_D+t_{\rm PP}
                 +\frac{t_{\rm SE}+2T_D}{16},& B_{R,\rm page}&=256\ \mathrm{Byte},\\
\Delta_R&=64(18T_D+t_{\rm PP})+4(t_{\rm SE}+2T_D),&B_R&=16384\ \mathrm{Byte}.
\end{align*}
同一组字节和时间一起聚合，所以两种写法得到相同 $\tau$。参考点的 4 次 45 ms 擦除、64 次 0.4 ms 页编程及 5.8\,$\mu$s 装入/控制合计
\[
\Delta_R=180\,\mathrm{ms}+25.6\,\mathrm{ms}+0.0058\,\mathrm{ms}
        =205.6058\,\mathrm{ms}.
\]
内部擦除占约 87.55\%，页编程占约 12.45\%，低压装入与控制不到 0.003\%。\sid{NOR-02} p.~38 也明确指出较高输入时钟下 Quad 输入的收益会被内部页编程时间淹没；缩短装入不能消除 $t_{\rm PP}$ 和 $t_{\rm SE}$。

\textbf{互补核查不更换主预算。}\sid{NOR-01} p.~45 Table~16 的 512 Byte buffer 编程为 420/1050\,$\mu$s，128 KiB sector 擦除为 410/1100 ms；擦除已含把所有 word 预编为零。其 typ 条件是 25$^{\circ}$C、3.0 V、10000 次循环和随机数据，max 条件另见注 31。1.64\,$\mu$s/word 是满 buffer 的摊销量，不能当作独立 word 完成延时；p.~2 摘要速率不能优先于这个详细条件表。本章没有把 NOR-01 的 128 KiB 擦除时间配到 NOR-02 的 4 KiB 粒度。

更新终点是页/sector 操作完成、状态可数字读取；初始上电、保护配置和异常操作恢复不属正常重复服务。NOR 的正常读不破坏状态，本时间窗口不增加 refresh 或 restore。有限 program/erase 耐久度单列为寿命约束，不并入瞬时 $\tau$。

\subsection{边界、可复现性和后续使用}
本章以同一份 binary 状态连接两路估算：读资源保持 R0，写资源始终单域。读写共享阵列与高压选择，估算中不重叠，因此 $P\leq\min(\rho,\tau\mathrm{RI})$ 只是必要上界，不保证两路同时达到各自独立峰值。静态权重 $Q_R=0$ 时进入 $\mathrm{RI}=\infty$ 分支，只受 $\rho$ 限制。

主要待验证条件是：128-SA 宽读分片的读窗/负载、32 片并行选择，sector 内八片共享擦除与页选择的隔离，以及在这些改造下仍保留所采用的完整 program/erase 时间。没有同芯片全链路实测，并不阻止本条件预算；也不能据此将结果推广为所有 NOR CIM、特别是连续模拟精调模式的性能。

\subsection{阶段、寿命与复算检查}
共享规则 R4 在此有两处作用：完整随机读预算替代其已含的选择/建立/感测；完整 BUSY program/erase 替代内部脉冲、verify 和恢复。公共数字归约、页数据装入和本地控制另算。未报告的高压切换或内部重试没有再人为加一个跨介质统一倍数。

\sid{NOR-02} p.~5 标称每 sector 至少 $10^5$ 次 program/erase 及超过 20 年保持。持续任意整矩阵重写每次消耗每个活动 sector 一次擦除寿命；这些商品条件不是改造后宏的寿命保证，也不是可以无限持续以 $\tau$ 更新的承诺。主预算未用这些寿命数去折减瞬时吞吐。

从本案例目录执行 \texttt{python scripts/check\_nor.py} 可只读核对结果；修改明确输入后执行同一脚本的 \texttt{--emit}，再执行 \texttt{sh scripts/build.sh}。构建采用 XeLaTeX/ctex/Fandol，渲染检查全部页面。共享参数变更会触发哈希/派生结果不一致，需复核后显式更新；不会静默沿用旧表。
