# 方法与检查说明

原生配置为K=4608、N=480，一个64-block subarray。13824 BL来自每输入三个二进制编码位置，三个SSL表示两位权重，四块组成INT8；30个数据WL、2个参考WL。36个cell/weight是必要编码，逻辑容量不重复计复制。四组1152项依次选通，20.736 µA名义峰值低于固定25 µA前端范围；全4608项同时打开的82.944 µA配置不进入主结果。

## 状态、前端与模式资格

NAND-04 PDF p.2 II-A明确低/高阈值两态均采用write-verify以调节Vt。NAND-05 PDF pp.2–3 Fig.6报告SLC分布、VG≫Vt饱和ON平台及全块随机编码后的2 nA电流分布。所需阈值控制不是无控制二态，也没有证据要求额外逐cell模拟电流精调。完整program预算按覆盖所需二态write-verify采用；NAND-06 pp.25、31、58的完成与成功status只提供异实现SLC完整P/E锚点，不证明SGVC ON电流分布或计算误差。

NAND-04 p.3 Table1的BL 12 ns限定50% sparsity，SL530–750 ns为max-bit输入映射HSPICE模型。当前保留2 nA、原器件偏置、原生16 pF SL负载与电流通路，活动BL分组、码分布及0–25 µA前端额定改变。530/640/750 ns是条件桥接，不是1152项的直接实测，不按I/C缩放整个周期，也不增加16 pF反馈电容。

`inputs.service_modes`声明正常求值、装载校准、page内部program/verify。`service_parameter_bindings`由公共`resolve_service_parameters`消费：SL/BL/WL、ADC与数字时间同步进入求值和校准；数字拍还进入页装入和metadata。PB内部verify采用内部偏置和感测路径，包含于完整program，与SL多bit校准不是同模式。未知override拒绝。

## 数值服务资格

理想65536个标量对的恒等式检查与量化后服务分开。`data/quantization_diagnostics.json`保存10个确定性向量、四个1152项组及各组16个digit对的单位计数、ADC码和重构计数。顺序为：偏置编码→按组求digit电流→名义10-bit ADC→24-bit仿射系数→整数计数舍入→base4重构和跨组累加→最终偏置校正。ADC步长25 µA/1024、half-up舍入、0…1023码；零/满参考得到0/849码，增益取Q8.16，offset取Q12.12且名义为零。固定格式只规定本参考数字实现。另存无限精度校准系数结果，确认误差并非人为数字舍入独自产生。

所有名义向量均无裁剪，半输入校准残差0.5码，小于4码规则；小信号仍能变号。故不能将检查执行成功、代数成立、参考校准通过或满量程相对误差较小当作一般signed INT8数值资格通过。顶层`numerical_service_qualification`明确`weak_signal_guarantee=false`和`weak_signal_and_cancellation_not_qualified`。主三情景仅为条件近似求值预算，数值误差门槛需要应用服务定义，未凭空发明网络阈值。

约8 ENOB只列分辨尺度97.65625 nA（48.828125个2 nA单位电流），不是将ADC换成8-bit码，也不是噪声分布或误差界。额外确定性2.5 nA均值压力使满输入25.92 µA超量程；此项仅验证裁剪拒绝，不是器件分布、主情景或成功概率。

缩组会增加转换次数，固定量程下的绝对ADC步长不变；缩量程又需要新的前端/建立依据。调参考码使个别向量恰好正确不认证其他输入。符号位分离/差分读取涉及额外控制、转换与重构，现有NAND-04/05的非负复制映射没有给出足以沿用时序认证当前signed实现的证据，故不以这些未落实方案修改主值。

## 完整服务与独立检查

更新由单域6144页program与64块erase构成，包含384参考页。完整SLC典型/最大P/E是跨实现锚点，没有按1728 Byte页比例缩时。480×21-bit metadata由规范副本生成，额外138240数字拍计入。480×30-bit中间累加、16×30-bit校正通道及480×29-bit最终输出分别列账。全部数据、metadata和校准成功才发布，没有全矩阵shadow。

```text
Delta_S = 30*303 + 480*(12+640+20+3*5) + (288+60+2)*5
        = 340600 ns
C = 2*303 + 12*(12+640+20) + 450*5 = 10920 ns
T_R = 6144*(300000+110*5) + 64*1000000 + 138240*5 + C
    = 1911281320 ns
rho = 13.5290663535 MB/s; tau = 1.15725507117 MB/s
RI* = 11.6906520356; U* = 5611.51297710 = 480*RI*
```

扰动测试以独立阶段次数为预期：SL/BL/ADC每增加1 ns，ΔS增加480 ns、T_R增加12 ns；WL对应30/2；数字拍对应1790/814530；完整program对应0/6144；erase对应0/64。检查同时确认U*恒等式。9组本地检查覆盖上述传播、理想编码、量化不利结果、完整装载、原PDF哈希与派生同步；这不是电路验证或一般数值服务验收。
