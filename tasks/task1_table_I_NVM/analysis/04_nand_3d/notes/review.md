# 当前参考设计与验证说明

主情景c=1已完成有限数值估算，c=108仅作一个组织对照。两者使用同一原生结构、积分电容/摆幅、物理装入量、完整程序/擦除预算与有限校准规则；逻辑格式相同，随机误差能力不同。

## 原始证据与工程预算

1. NAND-04 pp.7–8 Fig.8/9明确研究无input decimal mapping的低电流求和。108复制不是逻辑或INT8功能所必需；无复制时不能直接搬用max-bit场景的SL速度或算法准确率。
2. NAND-05 pp.1–3给出2 nA均值、0.3 nA标准差及饱和平台。主情景新增128×16 pF积分电容，0.4 V有用摆幅；T=CΔV/I得到25 μs。原生SL寄生约16 pF另保留。反馈前端建立/恢复各530–750 ns是负载锚定的预算，恢复为新分配，非测量。
3. c=108积分缩至231.481 ns，需每路27.648 μA、1.728 V/μs充放电/压摆能力，128路总信号电流3.538944 mA；这些是必要驱动条件，非功耗测量。c=1对应每路0.256 μA、0.016 V/μs。
4. NAND-01的MLC program 1.3/2.5 ms、TLC maximum 5 ms支撑完整操作窗口量级；两列erase同为15/45 ms。P=1.3/2.5/5 ms、E=15/30/45 ms为显式服务预算，不能称SLC固有/保证上下界。借用高压/写验/擦除完整块规模，不迁移多级终点、不按cell或页大小缩时。两阈值工作于宽窗口/饱和平台，不增加逐cell多级电流精调。
5. NAND-02的verify阶段和SLC burst泵保持机制用于保留必需操作，不提取11%加速或die带宽。
6. NAND-05 Fig.12支持已知码、除法/寄存器和推理乘法。选定2校准WL、三次采样/两次WL设置、226个数字拍，使C成为有限推导量。每次求值额外一拍数字校正，kA=3；128个小乘法器和系数寄存资源明示。

完整桥接表见`parameter_evidence.md`。binary verify超P、erase verify超E或校准半量程复测失败时，不发布矩阵、不计完成payload；返回失败而非无界重试。有限范围描述满足所选预算/终点的参考操作，不估计成功率或所有器件的最坏情况。

## 计量与复算

两subarray共128块仅实现一份状态；八个权重位平面×16输出，八数据WL覆盖128输出。每块实际八个有用数据页和两个参考页。整矩阵16384 Byte=1024数据页；append重算校准、持续重写为1280 program+128 erase+校准。完整页1728 Byte通过128-bit接口装入108拍，再加两拍控制。校准页和内部复制都不增加payload，未用WL/SSL不能自动摊销erase。

`check_nand.py`通过importlib导入共享acim_service、front_ns、program_sequence_ns、metrics；共享理论/参数/API未改。当前8组检查覆盖哈希、真实页/逻辑覆盖、电荷时间与资源、不同WL/求值次数、有限校准、完整写擦/装入、公平组织对照、派生同步。数值检查不替代模拟前端稳定性、程序收敛或良率证据。
