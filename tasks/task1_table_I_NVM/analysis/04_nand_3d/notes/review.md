# 方法与检查说明

原生配置为K=4608、N=480，一个64-block subarray。13824 BL来自每输入三个二进制编码位置，三个SSL表示两位权重，四块组成INT8；30个数据WL、2个参考WL。36个cell/weight是必要编码，逻辑容量不重复计复制。四组1152项依次选通，20.736 µA名义峰值低于固定25 µA前端范围；全4608项同时打开的82.944 µA配置不进入主结果。

读出保留NAND-04的SL电流形成与SAR结构。16 pF是原生SL寄生，没有新增同值反馈电容。SL建立530/640/750 ns是明确条件预算；完整服务含BL形成、ADC、校准增益、base4重构、跨行组累加、输入和、符号校正及输出。公共TI与已覆盖的BL形成不重复收费。8有效bit ADC是近似归一化部分和，不能恢复精确14-bit计数；signed offset相减的误差敏感性仍需应用精度审阅。

更新由单域6144页program与64块erase构成，包含384参考页。NAND-06完整SLC典型/最大P/E是跨实现锚点，不是SGVC时序保证；没有按1728 Byte页比例缩时。program已含verify和恢复。480×21-bit权重和metadata由规范副本生成，额外138240数字拍计入。480×30=14400-bit中间累加器、16条30-bit校正通道与480×29=13920-bit最终输出寄存器分别列账。写开始撤销有效标志，全部数据、metadata与校准成功才发布，无并发读取旧/新混合状态。
