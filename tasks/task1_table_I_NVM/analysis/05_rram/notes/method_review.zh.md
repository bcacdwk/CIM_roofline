# RRAM 方法与验证

原Fig.3中四个64×32子阵列共享TBL；采用八个完整64×128宏分别承载bit-plane，CIMSEL依次覆盖四个32项输入组。K128/N64、65536cell、8192B。每宏同输出WL上16独立列BL/SL路径，八宏共128实际目标，16Byte事务；两半组×四输入组×64输出=512事务，完整覆盖8192位置。

编程域配置128个300µA限流驱动、38.4mA供给、256窗口比较器、128bit目标缓冲及mask/done。局部每lane切换负载≤1pF是参考实现约束：1.8pC/(300−225)µA=24ns。50/100/250ns为非零局部偏置/隔离/返回读验的条件预算，不是源文测得延迟或可靠性保证。写rail全矩阵保持，1µs起退各一次；不重复充当每attempt的高压上电。原始1µs实际pulse、外部1–10µs读回与本地窗口sense分开。

独立典型算术：

```text
DeltaS=128*(5+5+20+2*5)+2*5=5130ns
local16B=10+3*(1000+100+100+5+5+20+5+5)=3730ns
TR=512*3730+2000=1911760ns
rho=128/DeltaS=24.9512670565MB/s
tau=8192/TR=4.28505670168MB/s
RI*=5.82285575049; U*=64*RI*=372.662768031
```

完整矩阵与独立16Byte请求边界不同，后者加两端rail为5730ns。所有主情景的驱动、额定电流、比较器和负载上限相同；尝试和局部切换条件配对。16驱动仅资源对照，固定外围尝试扫描与50/100/1000ns切换扫描分别保存。

## 模式依赖与独立断言

`service_modes`中的正常求值沿T2/core/TBL，终验沿T1/IO/BL/SL及memory窗口比较器（RRAM-05 PDF p.3 Fig.3/4）；两个5 ns是不同路径的参考建立预算。CIM PH0的测量不证明memory窗口前端也等于5 ns。T_B直接绑定公共`adc_batch`，因为既定政策T_B=T_A借用同等采样/判决/锁存能力，而不是复用同一ADC。T_I和T_D同样传播所有消费者。

对参考情景每个参数增加1 ns，预期斜率由128个求值组、512个更新事务和每事务3次尝试直接计数。测试预期不用主生成器产生：

| 参数 | Δ_S增加(ns) | T_R增加(ns) |
|---|---:|---:|
| CIM前端 | 128 | 0 |
| verify前端 | 0 | 1536 |
| 公共T_A或T_I | 128 | 1536 |
| 公共T_D | 258 | 4096 |
| 局部选通或退偏 | 0 | 1536 |
| RESET脉宽 | 0 | 1024 |
| SET脉宽 | 0 | 512 |
| rail开始或退出 | 0 | 1 |

对每项还独立核对ρ=128e9/Δ_S、τ=8192e9/T_R及U*=T_R/Δ_S。直接修改输入中的两个前端字段，验证无写死5 ns残留；公共解析器拒绝未知参数。三主情景为固定资源、限定完成条件，W16为资源对照，局部切换为同模式参数敏感性，尝试扫描改变成功完成条件而非统计分位。

## 脉冲、窗口与参考次数

RRAM-01 PDF p.10的1 µs SET/RESET用于HfOx/TaOx模拟目标，gmax30/40 µS、容差±1 µS。本TaOx参考LRS窗8–12 kΩ等价于83–125 µS，不能用同脉宽证明达窗。RRAM-05 PDF pp.3–4、7的电阻典型值、m=1约0.5 µA与HRS低于30 nA支持二态读路径及校准目标，但未给8/12/70 kΩ边界的完整转移数据；该窗不是已验证的计算充分界。

RRAM-03 PDF p.5 E节/Fig.9只证明多数名义条件完成、少量追加的二态P&V类别；RRAM-06 PDF pp.1–2的RESET较慢、all-done、mask和timeout只支持非对称预算方向。2/1是在1/1上给RESET多留一次修正的参考选点，不是平均、分位或实测统计。每批预算由最慢活动lane约束，不将1 Mb中“数十cell”转换成128-lane成功概率。低于8 kΩ的LRS过冲需要额外反极性救援时，不在所列同极性有限情景内，不发布成功完整矩阵。
