# RRAM 方法审阅

本轮将工程参考预算与测量验证区分，已形成有限ρ、τ、RI*主情景。共同公式、JSON和API保持不变。

1. **策略与物理代价分开。** 单cell加每次完整公共SAR不是二状态RRAM的物理必需。RRAM-05 p.3的memory电流SA与CIM感测解耦；RRAM-06每IO双组TM-WT、mask与all-done控制支持明确配置的局部并行。主例选择八位平面×双列组=16lane，代价为16耐压驱动、32窗口比较器和完整地址/状态资源。
2. **几何完整。** 一个输出WL上，G0含输入列0–15，G1含16–31；本事务写0–7和16–23，八批各选每组一列、每列八位平面，共128cell/16Byte。另一事务覆盖其余16列。RESET和SET分相，未假设同WL可以同时混合脉冲极性；RESET不隐藏到idle。
3. **操作锚点可以跨实现借用，但不能移用成功统计。** NeuRRAM实际1µs SET/RESET及1.2/1.5V、0.1V步进可以作为参考波形；它的HfOx(+TaOx热增强层)与RRAM-05 TaOx不同。目标LRS 8–12kΩ即83–125µS高于原30/40µS；较宽二态窗不证明尝试次数更少。1/1、2/1、4/2是完整运行情景，未到窗不记成功payload，不声称良率分位数或普适上限。
4. **本地sense口径统一。** memory窗口比较/采样/锁存采用共同10/20/50ns能力时隙，另计T_I和5ns建立；PH0=5ns与PH1 intrinsic5ns支持局部量级，但没有把4bit周期直接变成binary实测时延。NeuRRAM1–10µs读回受外部控制影响，不用于压低主局部服务。p1 binary与p1 SAR按同一预算得到相同数值，主收益归因于明确的16lane资源。
5. **完整占用已落实。** 主参考ΔR=72.970µs，由24µs脉冲、48µs HV建立/恢复工程余量、0.72µs选通/感测、0.25µs控制组成。ρ=0.0124878GB/s、τ=0.219268MB/s、RI*=56.9522。单lane对照ΔR=1167.370µs、τ=0.013706MB/s、RI*=911.118；固定部分之后的物理占用恰为16倍。
6. **仍待校准的是两个具体条件。** 所选波形在目标cell上达到窗口的组内尝试次数，以及跨stack程序/本地sense接口适配。这些影响真实实现的取值，但不阻止有来源锚点、步骤完整的条件工程估算。无需先验证完整良率、算法精度或同芯片两路测量。

维护、FORMING与寿命不混为逻辑更新需求。没有把10ns读扰脉冲、1–10ns控制器能力、归一化改善或封装毫秒提交作为本地主写时间。当前主交付只保留完整物理服务的有限情景与同预算策略对照。
