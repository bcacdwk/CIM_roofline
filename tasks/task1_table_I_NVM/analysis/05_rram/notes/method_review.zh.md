# RRAM 方法审阅

本轮已核对全部六份 RRAM PDF 的相关正文；关键图表包括 RRAM-05 的 Fig.3/4/9/10/16–18，RRAM-06 的 Fig.3–10，RRAM-01 Methods，RRAM-02 Fig.1/2，以及 RRAM-04 p.17 AC 表。页码采用 PDF 页序。

共同方法可以继续使用，未发现需要改写 ρ、τ、RI* 定义或顺序计算接口的错误。以下是媒体接入层必须保留的实质问题：

1. **阶段替换不能变成随意减法。** RRAM-05 的四位参考扣除读出 66 ns（实测 access）和 13 ns（作者优化估计）并不匹配公共 SAR 的码宽与前端接口。本例保留 PH0 电流建立/漏电补偿，以 `5 ns + h_A` 表示前端；公共 `T_I` 在阵列访问关闭时完成输入形成，明确与访问后的 PH0 顺序分离。公共 SAR 替换量化功能，仍需电流转电压、共模、采样负载及校准条件。没有把 66 ns 加 SAR，也没有无依据把 13 ns 拆为器件时间。
2. **写数据口与真实驱动并行不同。** RRAM-05 通过 AX/AY/DIN 逐 cell 选通，本文保守选择一个单 cell 编程域；RRAM-06 的双组自终止说明等待组内最慢完成和独立控制的重要性，但没有给出可移植的绝对写时间。不能从 128-bit 接口或128颗ADC推128-cell同时写。
3. **失败与“可计算”需要媒体输入。** 共享 `program_sequence_ns` 求和的是已经声明的操作列表，不会自动解决成功率、重试、超时与坏位替换。源文 binary threshold 和 CIM 合格电流窗口也不等同。机器结果把缺失主 τ/RI 设为 `null`；数学下边界以零未知物理占用计算，有明确标签，不能生成正式介质点。
4. **相同状态的证据必须相容。** NeuRRAM 的1 µs、8.52脉冲、56 µs投影属于另一stack与多级差分配置；RRAM-04的8.5–25 ms属于封装数字存储提交。两者可以解释操作层级，不与B32读侧配对。
5. **串行控制策略已能提供非空约束。** 按当前逐cell pulse+同SAR verify策略，参考点已知控制/读验成本40 ns/cell，ΔR≥5130 ns，τ≤3.1189 MB/s，RI*≥4.0039。`u_crit(RI*=1)=9.9316 ns` 小于已计成本，因此在本策略内不可达；这并非RRAM材料的ridge下限。二状态完整更新需多快才能落在RI*=10或100由门槛表给出。

数值所有结构/计数/服务/指标调用共享接口。`h_A=5 ns`仅是额外一个PH0时隙的工程敏感性对照，不是测量范围；也同时进入写验。末端保持/维护若后续发现需要，应加入资源占用而不增加逻辑Q_R。主基线当前不需修改。
