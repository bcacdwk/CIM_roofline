# RRAM 方法与验证

原Fig.3中四个64×32子阵列共享TBL；采用八个完整64×128宏分别承载bit-plane，CIMSEL依次覆盖四个32项输入组。K128/N64、65536cell、8192B。每宏同输出WL上16独立列BL/SL路径，八宏共128实际目标，16Byte事务；两半组×四输入组×64输出=512事务，完整覆盖8192位置。

编程域配置128个300µA限流驱动、38.4mA供给、256窗口比较器、128bit目标缓冲及mask/done。局部每lane切换负载≤1pF是参考实现约束：1.8pC/(300−225)µA=24ns。50/100/250ns为非零局部偏置/隔离/返回读验的条件预算，不是源文测得延迟或可靠性保证。写rail全矩阵保持，1µs起退各一次；不重复充当每attempt的高压上电。原始1µs实际pulse、外部1–10µs读回与本地窗口sense分开。

独立典型算术：

```text
DeltaS=128*(5+5+20+2*5)+2*5=5130ns
local16B=10+3*(1000+100+100+5+5+20+5+5)=3730ns
TR=512*3730+2000=1911760ns
rho=128/DeltaS=24.9512670565MB/s
tau=8192/TR=4.28505670168MB/s
RI*=5.82285575049; U*=64*RI*=372.662768031
```

完整矩阵与独立16Byte请求边界不同，后者加两端rail为5730ns。所有主情景的驱动、额定电流、比较器和负载上限相同；尝试和局部切换条件配对。16驱动仅资源对照，固定外围尝试扫描与50/100/1000ns切换扫描分别保存。
