\section{二状态 RRAM 的局部求值与有限写服务预算}

本节采用二状态 HRS/LRS、八个等尺度权重位平面、32 项局部求和，以及 16 个独立编程/二状态校验通道。在共同 28 nm 外围条件下，三个成对工程情景给出 $\rho\approx0.00588$--$0.02379\GBs$、$\tau\approx0.10804$--$0.33099\,\mathrm{MB/s}$、$\RI^*\approx54.4$--71.9；参考点分别为 $0.01249\GBs$、$0.21927\,\mathrm{MB/s}$ 和 56.95。它们是\emph{完整步骤和成功条件明确的参考服务预算}：波形与读回量级由本地文献锚定，驱动资源、恢复余量和尝试次数由本文选择。它们不要求先复现同一芯片的全部实测，也不被解释为材料固有范围或测量保证区间。

\subsection{状态实现、共同任务及读侧计数}

共同任务仍为 $128\times128$ INT8 矩阵乘 INT8 向量，$b_S=b_R=1$ Byte/element，交付 128 个 24-bit 容器。输入接收到结果就绪是 streaming 边界，resident 边界则从本地命令/数据接收到对应状态可计算。八个位平面保存补码权重，数字重构对符号位使用 $-2^7$；一个逻辑 INT8 权重占八个二状态 cell，全矩阵为 16384 Byte、131072 cell，物理广播、位展开和重试不重复增加 payload。

读结构以 \sid{RRAM-05} 的 28 nm TaO$_x$ WH-2T1R 为锚点。T1 承担 memory 选择，T2 构成解耦的 CIM 通路；其 $64\times128$ cell 阵列含四个 $64\times32$ 子阵列，32 项电流求和有直接测量支持。原文以 $m=1,2,4$ 的 T2 尺寸及 MSB 冗余组成三位空间权重（PDF p.3 Fig.3/4、p.4 Fig.7）。本文采用八个相同 $m=1$ 平面，不沿用空间加权或冗余择优：每平面四个 32 输入组、两个 64 输出块，总共 64 个 $32\times64$ 子阵列构成同一矩阵，未复制独立服务单元。

在 $V_{\rm TBL}=0.1$ V、$V_{\rm BL}=0.3$ V、$V_{\rm WL}=0.6$ V 时，$m=1$ 的 LRS 电流约 $0.5\,\mu$A/cell，扣除泄漏后的 HRS 小于 30 nA；Fig.17 展示到 32 个活动 cell 的线性求和。沿用 R0 的八平面并行、每平面16 ADC、16数字输出通道和每轮两拍重构；32 项二进制部分和 $0\ldots32$ 需六位码，使用共同名义十位/有效约八位 SAR。计算语义为经校准的近似 ACIM 重构，没有新增必须满足的算法误差证明。

原 RS-CSA 的 PH0 承担电流稳定及漏电补偿，实测时隙 5 ns；PH1--PH4 逐次比较并扣除参考，实测四位输出 access 为 66 ns，13 ns 是作者优化估计（PDF p.5 Fig.9/10、p.7 Fig.18）。本设计保留 PH0 对应前端，并用公共 SAR 替代量化功能，取 $t_{m,A}=5\ns+h_A$。公共 $T_I$ 在访问关闭时完成输入形成，随后才使能阵列并建立电流，不再次把同一输入建立塞进 PH0。主情景采用 $h_A=0$ 的接口预算；电流转电压、共模及采样负载需相容，额外 $h_A=5$ ns 仅作为接口敏感性。66/13 ns 都不与公共 ADC 时隙叠加。

每向量 $B_S=128$ Byte，八输入位、四行组、八个16输出组依次执行，因此
\[
 (N_E,N_C,N_{\rm rec},N_{\rm dig})=(256,256,256,512),
 \qquad N_{\rm scalar}=32768.
\]
无跨组模拟保持和跨向量流水，输入捕获与结果提交共两拍。共享 A 模板给出
\begin{equation}
\boxed{\Delta_S=256(T_I+5\ns+h_A+T_A+2T_D)+2T_D,\qquad
\rho\approx128\,\mathrm{Byte}/\Delta_S.}
\label{05_rram:eq:stream}
\end{equation}
共同短/参考/长时隙为 $(T_I,T_A,T_D)=(2,10,2)$、$(5,20,5)$、$(10,50,10)$ ns，故主情景的 $\Delta_S$ 为 5.380、10.250、21.780\,$\mu$s。

\subsection{二状态程序：可借用的操作锚点与成功窗}

\sid{RRAM-05} 的典型 $R_L/R_H=10/100\,\mathrm{k}\Omega$，Fig.7(b) 的模拟条件另列 LRS 10\%、HRS 30\% 变化标准差。本文据此选一个可检验的二目标验收条件：
\[
 \text{bit 1：}R_L\in[8,12]\,\mathrm{k}\Omega,
 \qquad \text{bit 0：}R_H\geq70\,\mathrm{k}\Omega.
\]
这是围绕典型状态的\emph{设计窗口}，并非由标准差推出的良率界。memory 通路用每 lane 两个可切参考的 binary 比较器判定 LRS 上下窗或 HRS 单边门槛；参考电平在所选读偏置下标定，验收的是同一组将被 CIM 使用的 cell。八位逻辑权重仍由八个二状态 cell 表示，没有引入中间模拟级。

\sid{RRAM-01} 的 NeuRRAM 实验实际采用 1\,$\mu$s SET/RESET 脉冲，初始 SET/RESET 幅度为 1.2/1.5 V，失败后按 0.1 V 步进，读回耗时 1--10\,$\mu$s。方法见 PDF 第10页，波形见第18页扩展数据图3。\sid{RRAM-02} 的 28 nm Fig.8(b) 又给出最终 SET 的 BL 电压约 1.1--1.5 V（PDF p.7）。这些证据可支持可调专用写域和微秒级\emph{操作预算}，不必要求其原宏与目标参考设计完全相同。

桥接范围必须明确：NeuRRAM 是 HfO$_x$ 含 TaO$_x$ 热增强层，\sid{RRAM-05} 为 TaO$_x$，属于跨 stack 波形借用。本文 LRS 窗对应约 83--125\,$\mu$S，比 NeuRRAM 的 $g_{\max}=30/40\,\mu$S 更高；虽然窗口比其 $\pm1\,\mu$S 精调更宽，\emph{不能据此证明所需尝试更少}。因此只借 1\,$\mu$s 脉宽与可调幅度的操作锚点，不移用 8.52 次平均脉冲、56\,$\mu$s/cell 集成投影、99\% 成功率、三轮再调谐或30 min测试等待。

参考程序固定每次 SET/RESET 脉冲为 1\,$\mu$s；初始幅度取上述 1.2/1.5 V，同极性失败时每次增加 0.1 V，所列情景最高 SET/RESET 为 1.3/1.8 V。器件需能在所选可编程电压和限流条件下达到目标窗，这是参考实现的条件；不以这些电压反推切换速度。每次高压建立和写后回读偏置/恢复各预留一个 1\,$\mu$s 波形时隙。两项是明确的工程余量，既不是原文测量，也没有用数 ns 的低压数字拍代替它们。

本地 binary 读验采用统一的外围能力预算。输入/地址选通用 $T_I$，读回前端另取5 ns建立；窗口比较、采样及锁存的完整时隙取 $T_B=T_A=10/20/50$ ns。\sid{RRAM-05} 的 PH0=5 ns、PH1 内在延迟5 ns支持局部建立/判决的量级，完整sense时隙则沿用共同能力预算，\emph{没有按SAR位数缩放}。这个memory窗口前端的适配属于工程选择；组内done归约与mask提交另计一拍。NeuRRAM原1--10\,$\mu$s读回及外部DAC/ADC控制限制保留在证据表，未被强加为本地binary SA的内在延时或主服务等待。

\sid{RRAM-03} 的二状态 1 Mb P\&V 显示，大多数 cell 在名义条件完成，少数需要追加；每次 SET/RESET 后读比较阈值（PDF p.5）。\sid{RRAM-06} 则显示组内等待最慢完成、RESET 较慢和自终止机制，但绝对时间轴被归一化。因此选 $(K_R,K_S)=(1,1),(2,1),(4,2)$，分别表示两相位一次完成、RESET 多一次修正，以及 RESET 三次追加/SET 一次追加的运行情景。$K$ 是\emph{一批最慢活动 cell 的预算尝试数}，不是实测分位数、普适上界或由模拟平均值折算的数字。通过的 lane 由 mask 关闭；最终全通过才算成功 payload。超过该情景次数而未到窗的服务不计为该情景成功，超时按失败报告。

\subsection{16-lane 写组织、几何映射及完整步骤}

\sid{RRAM-05} 的 memory 电流 SA 与 CIM 的多位 RS-CSA 分开，故二状态写验并不物理必需逐 cell 调用完整公共 SAR。\sid{RRAM-06} 进一步给出每 IO 两个 G0/G1 写终止模块、两套共享 AWC/YMUX 控制以及组内全 done 后推进的组织（PDF p.1、p.2 Fig.3--7）。本设计以八权重平面对应八 IO，每 IO 配两个编程列组，明确选择 $p=8\times2=16$；这不是从128-bit数据口推断出来的并行度。

几何如下。固定一个输出位置及其在八位平面上的同一物理 WL，32 输入列分成 G0 的0--15列与 G1 的16--31列。一个16权重事务选 G0 的0--7列和 G1 的16--23列。第 $k=0\ldots7$ 批在每平面选择列 $k$ 和 $16+k$：每批完成两个逻辑权重的八位，共16 cell；八批恰好覆盖16个完整 INT8 权重的128 cell。另一个事务覆盖8--15和24--31列，重复至全部行组/输出即可覆盖同一矩阵。128-bit 本地缓冲完成 payload 到平面/列组的转置，不改变 $B_R=16$ Byte。

同一 WL 不假设能同时混合两种脉冲极性。更新先对这128 cell 分八批 RESET 并校验，再按目标为1的 mask 分八批 SET 并校验；两相位都完整计时。非目标 cell 在 SET 中不导通，但本固定调度仍保留该相位预算，不从数据稀疏或地址跳过额外加速。每批等待两个列组内的活动 lane 全部通过才推进。这个 RESET-first 策略借鉴 \sid{RRAM-06} 的组织，而没有把 RESET 隐藏到 idle 或算成免费预处理。FORMING 是进入正常更新模式前的初始化，不逐次重做。

新增资源为16个独立耐压写驱动及限流/关断支路、32个 binary 比较器、两个组地址计数器、每 lane 数据/活动/done 状态和一个共同控制域。每 lane 的电源能力预算取0.30 mA，阵列峰值预算4.8 mA；最高1.8 V除以LRS窗下界8\,$\mathrm{k}\Omega$ 为0.225 mA，只用于量级核对，\emph{不声称它是动态编程电流测量或必需限流值}。需有支持1.8 V的独立I/O器件、电平转换和限流资源，不能用 \sid{RRAM-05} 的core 0.8 V/IO 1.2 V测量供电证明耐压。以上并行发生在一份矩阵内，未增加独立 bank/服务单元。

命令与首个128-bit编码数据批同拍，事务准备/最终提交共 $2T_D$。每次尝试按“地址与模式控制一拍、HV建立、1\,$\mu$s脉冲、回读/恢复、binary选通/建立/完整sense时隙、组内done归约/掩码提交一拍”执行。成功完成的完整 resident 间隔用共享 D 模板表示为
\begin{equation}
\boxed{\begin{aligned}
 B_R&=16\,\mathrm{Byte},\qquad N_P=128/16=8,\\
 \Delta_R&=2T_D+8\sum_{z\in\{R,S\}}K_z
 (t_{\rm HV,up}+t_{p,z}+t_{\rm HV,return}+T_I+5\ns+T_B+2T_D),\\
 \tau&\approx B_R/\Delta_R,\qquad
 \RI^*\approx\frac{128}{16}\frac{\Delta_R}{\Delta_S}.
\end{aligned}}
\label{05_rram:eq:resident}
\end{equation}
这里 $N_P$ 表示物理编程批数；数据装入仍只有一拍。内部 RESET/SET、失败重试和位平面不增加逻辑写入字节。

\subsection{R0 对接、估算边界与复算}

R1的共同任务、单矩阵边界及近似ACIM合同不变；R2依据32项证据增加行分组；R3保持八位平面、128 ADC、16数字通道和无模拟保持；R4保留5 ns专用前端并按公共SAR预算适配；R5明确增加16个编程lane和专用binary窗口感测，计入实际两相位操作及掩码/重试。并行资源没有等面积等成本主张，也没有把128-bit口直接当成128-cell编程。结构及两路随动记录均见输入JSON。

本轮不确定性收敛为两项：选定程序和窗口在目标cell上对应的组内尝试次数，以及跨stack编程波形及本地窗口感测预算的适配。本文已把它们变成可复算的有限情景及完成条件，不要求先取得完整良率、算法精度或同芯片两路实测才允许工程估算。相应地，主范围也不包含未达窗的失败尾部，不能被引用为通过认证的最大写时长。原文的10 ns读扰脉冲、1--10 ns控制器能力、归一化page-write改善，以及封装产品的毫秒提交都未被偷换成本地完整写周期。

读后恢复没有被添加为RRAM必需维护；若部署条件需要状态重新校准或保持维护，应计入资源占用，不能增加逻辑 $Q_R$。耐久与寿命另作可行性约束。读写作用于同一阵列，独立memory SA不自动提供同时读写；两路独立服务能力仍受同一边界内资源互斥约束。

完整计算调用共享接口；输入JSON保留原值、工程选择与来源，结果保存映射、占用及各项对照。脚本核对128cell/16Byte覆盖、分相/重试、完整服务和源文件哈希；数值表由数据生成。
