\section{主模式、证据角色与逻辑映射}

采用 \sid{MRAM-06} 的互补二进制 MTJ 与 bitcell 内数字化机制：每个存储 bit 用两个 MTJ 分别保存 $W$ 和 $\overline W$，输入触发差分感测，产生数字 AND，后续用整数加法树与移位累加形成结果。该论文为 \textbf{40 nm} 实测宏；本文沿用其机制，按共同的 \textbf{28 nm、近标称 0.9 V/25\,$^\circ$C 外围参考}构造局部设计，绝不把原 540 MHz@1.2 V、最佳能效@0.65 V 与较高电压无观测读错拼成一个工作点。

\sid{MRAM-03} 是 28 nm 1T1MTJ 普通存储宏，提供完整写 access 与感测时序锚点；\sid{MRAM-04} 的 28 nm 2T2MTJ 差分存储宏补充读时间尺度。二者用于支持工程时隙，均不能直接提供本文数字 CIM 的完整 MVM 周期。\sid{MRAM-01} 则是电阻串联求和、时间域读出：其 13--29 ns 列响应、11.1 MHz 运行和左右两侧各写一拍属于另一组织，本章不将它们代入数字路径。

共同任务是 $128\times128$ INT8 矩阵乘 INT8 向量。$b_S=b_R=1$ Byte/元素，$B_S=128$ Byte；逻辑权重容量 16384 Byte，输出为 128 个 24-bit 整数。物理状态是
\[
128\times128\times8=131072\ \text{互补 bit 对},\qquad
2\times131072=262144\ \text{MTJ}.
\]
八个位平面共同表示一份矩阵，符号位采用补码负权；不因互补编码或输入展开增加逻辑 payload。DCIM 的精确性指整数算术无量化损失，仍以正确存储与感测为前提，不是系统 BER 保证。

\section{Streaming：逐位展开与完整数字服务}

\sid{MRAM-06} 的原生数字 bitcell 支持输入触发的数字 AND。原宏每 bank 在一拍内处理 256 个一位输入与四位权重，四位输入仍需四拍；更高权重精度通过 bank 合并。它支持多位重构机制，却不意味着任意 INT8 矩阵一拍完成。本文为统一比较采用 R0 的较小归约宽度，八位权重同时可用，逐个输入 bit 重新执行规定读服务，不用原文恒定输入可保持输出的特例减少最坏数据调度次数。

完整 MVM 的轮数由逻辑覆盖得到
\[
N_D=N_{\rm rd}=8\ \text{输入位}\times
\frac{128}{32}\ \text{输入组}\times
\frac{128}{16}\ \text{输出组}=256.
\]
每轮先用 $t_m$ 完成所选 bitcell 的预充/恢复、专用读建立及数字化，再用共同 $T_D$ 完成 32 项整数归约与累加更新。输入捕获和最终提交另各一拍，阶段顺序执行，无跨向量流水复用假定：
\[
\boxed{\Delta_S=256(t_m+T_D)+2T_D,\qquad
\rho=\frac{128}{\Delta_S}\ \mathrm{GB/s}\quad(\Delta_S\text{ 以 ns 计}).}
\]
这里没有 ADC 或 TDC 时隙。$t_m$ 是本参考在所声明负载下的完整可复用媒体读槽，不能用单个 MTJ 的翻转时间或单个 latch 的传播延迟替代。

\subsection{读槽为何选择 3/5/10 ns}

\sid{MRAM-04} pp.1--2 在 28 nm、32 kb 2T2MTJ 宏给出 1.3 ns read access，读位线电压 0.3 V（不能把读位线偏置当成核心供电）。它与互补差分路径较接近，但属于专用 CRE-VSA 存储读，不能直接充当 bitcell CIM 的整轮时间。\sid{MRAM-03} pp.6--7 给出 2.8 ns@1.2 V、25\,$^\circ$C，约 $10^{-5}$ 读错误率；这个电压和错误率不能搬到新设计。

因此选择 $t_m=3/5/10$ ns 配合共享短/参考/长 $T_D=2/5/10$ ns。3 ns 短端依赖互补感测、小局部负载和足够的行驱动/隔离；5 ns 为参考移植预算；10 ns 允许更长的建立与恢复。它们是由完整存储读量级和 \sid{MRAM-06} 本地数字化机制支持的工程选择，不是固定 0.9 V 下的三个硅测 PVT 点。新增 4096 个活动 bitcell 的扇出、归约负载与读扰动仍需电路验证。

参考点 $t_m=T_D=5$ ns，故
\[
\Delta_S=256\times(5+5)+10=2570\ \mathrm{ns},\qquad
\rho=128/2570=0.04981\ \mathrm{GB/s}.
\]
其中媒体读占 1280 ns、数字归约占 1280 ns、边界占 10 ns。小 bitcell 的快速响应不会消除输入位展开和有限输出通道的 256 轮占用。

\section{Resident：两相互补写入与两支路状态验证}

\subsection{实际选通与电流路径}

\sid{MRAM-06} p.2、Fig.2b 和 SI p.4 Fig.2 明确两相写：先将\emph{两个 MTJ 都写为 P}，再把其中目标一侧写为 AP；本文严格保留该序列。不是“左侧一次、右侧一次”的任意互换，也不是 Flash 擦除。SI 原图对 256 对 bitcell 标出第一相 $512I_W$、第二相 $256I_W$ 的行电流，支持按真实活动支路计数。

本文每组 64 对，配置 128 条可选择极性的 MTJ 写电流路径及能够承受总电流的 SL 驱动。第一相 128 MTJ 同时置 P，所需总驱动能力为 $128I_W$；第二相各对只有目标一侧置 AP，64 条同时活动，需 $64I_W$。这些驱动及选择资源是本文配置，并非由 128-bit 数据接口推断得到。只提供 64 条第一相路径时必须分组重算，不能沿用本结果。

\subsection{验证覆盖物理互补性}

原论文 p.9 给出逐 row 写后读验、错误 row 重写，却没有完整写验绝对周期。单读一个差分逻辑输出可能漏掉 P/P 或 AP/AP 非法状态。本章增加\textbf{64 条单端 P/AP 感测通道及参考、左右支路隔离选择、64 个并行比较器和 128 bit 状态检查锁存}。每次分别读左侧 64 MTJ、右侧 64 MTJ，各用一个完整低偏置读槽 $t_m$ 和一拍比较；最后确认每支路匹配目标并且每对一 P 一 AP。

这是明确的参考电路扩展，原 \sid{MRAM-06} 的差分逻辑读不能免费提供独立状态验证。支路选择、低偏置模式建立和复位均放入所选读槽；比较拍累积 pair-valid 和 target-match。外部控制完成拍恢复计算模式。本组未写完、两支路未通过之前，不计 resident payload 完成。

\section{写时隙、失败预算与服务终点}

\subsection{原值、工程槽与覆盖边界}

\sid{MRAM-03} pp.5--7 描述写时同时感测和自终止。Fig.21 与正文给出约 20 ns 对应 $10^{-5}$ 级写错误及 47\% 节能；约 30 ns 时曲线已到 1 Mb 测试的 $10^{-6}$ \emph{零观测错误分辨地板}，正文同时报告 61\% 节能。地板不是测得的真实失败概率，更不是移植后概率保证。自终止主要支持节能，不能据此把外部服务槽改为平均翻转时间。

本文取 $t_W=20/30/30$ ns 为单方向完整物理写槽，覆盖该相驱动初始化、施加写电流、翻转/终止及恢复，锚定原 write access 的量级；不再另外加一遍裸写脉冲或任意高压余量。共享 $2T_D$ 是本地事务控制，额外一拍是两相之间的极性切换，两批低偏置验证独立增加。原论文没有可供逐项相减的延迟拆分，故这些是\emph{可审查的分阶段工程预算}，不是从原完整 access 中识别出的实测子项。实际电路若将其中阶段合并，应按共享 R4 替代覆盖项再复算。

\subsection{有限预算和成功判据}

主情景明确分配一次完整尝试，终点是两个 MTJ 的绝对 P/AP 状态都通过验证，故
\[
\boxed{\Delta_R^{(1)}=T_{\rm front}+C,\qquad
C=2t_W+2t_m+3T_D.}
\]
这是一次被验收的完整服务预算，不能称为无条件的每次写入成功时间。若校验失败，该组不产生有效 $B_R$，但已经耗费的两相写和验证时间必须保留。唯一的更新对照为\emph{恰好重写一次整组，第二次完成并通过验证}：
\[
\Delta_R^{(2)}=T_{\rm front}+2C.
\]
重试保留编码目标，重新执行先双 P、再选侧 AP、两批状态验证；不计第二遍 payload，也不重新计已保持的装载数据。此对照不是宣称两次必然成功；超出预算的失败事务不能纳入已完成吞吐，实际持续服务需用本实现的组重试统计修正。

每组第一相 128 个、第二相 64 个状态命令，总计 $192$。仅用于量级压力检查，将短/参考/长单命令输入记为 $p=10^{-5}/10^{-6}/10^{-6}$，锚定原 20/30 ns 数据与有限样本地板。形式上的组内 union bound $192p$ 为 0.192\%/0.0192\%/0.0192\%，组内不需独立性；但这些 $p$ \textbf{不是本文 2T2MTJ、0.9 V 与新负载的已验证概率}，因此不进入主表时间，不从它们推出新实现成功率或无限重试期望。

尤其是 \sid{MRAM-03} 的 2.8 ns 读本身带约 $10^{-5}$ 错误条件，独立单端验证不能被默认成无误。本文增加验证资源并明确覆盖全部物理状态，同时把正确感测作为参考设计待满足条件；必须以新偏置、负载和判决裕量验证误接受/误拒绝。20/30 ns 仍是有文献量级锚点的有限工程写槽，可靠性数据缺口不改变两相、验证批次和实际驱动计数。

\subsection{局部事务可聚合为整矩阵更新}

对齐的八权重组不需要先擦整页/整块。一个 $128\times128$ 矩阵可顺序执行 $16384/8=2048$ 个相同事务；有效 payload 和所有服务占用都乘 2048，故 $\tau$ 不变。参考整矩阵时间约 $194.56\,\mu$s；这保留每组控制，并未暗中摊薄开销。稀疏单权重写若仍动用整组，需要明确掩码/保留数据及有效字节，不能仍以 8 Byte 计入一次一权重更新。维护、编码和失败重写均不重复增加 $Q_R$。

\section{适用边界、维护与后续实测重点}

本章主模式的读为非破坏性读，服务窗中 refresh 和破坏性读 restore 占用均取零。\sid{MRAM-03} 在其读偏置及约 3 ns 访问条件下报告超过 $10^{16}$ 次连续读取未观察到扰动，这是\emph{读扰动实验}，不能改称写耐久寿命。本文需要低偏置和读时间满足新 bitcell 的扰动约束；若加入周期检查/刷新，必须计入该局部资源的维护占用。

写耐久和保持作为独立可行性条件，不混入瞬时 $\tau$。本两相机制先双 P 再选侧 AP，每次写入对不同物理 MTJ 的切换负担不同；工作负载、温度、偏置与厂商允许次数共同决定寿命。没有来自所建参考单元的写耐久验证，故不嫁接资料中其他器件的最佳循环次数。

\sid{MRAM-05} 的 xSPI 产品在 persistent memory 模式下支持连续写、无页跨越限制，并把 ERASE 用于命令兼容。它可以支持“STT 更新不必物理先擦除”的语义，不提供本地 bitcell 写并行度或 28 nm timing。本章两相置 P/置 AP 是所选互补 bitcell 的写法，不能升级为全部 MRAM 的必要写步骤；其他 1T1MTJ 或电阻求和组织须另外定义读写路径。

可直接用于后续 Table I 的是\emph{所声明互补 DCIM 主模式}下的配对结果。尚需电路或硅测收敛的三点为：4096 个活动 bitcell 与 16 路归约的 3/5/10 ns 读预算；128 路第一相并发电流和跨相恢复是否满足 20/30 ns 单相物理槽；64 条单端验证通道能否在两批中可靠识别 P/P、AP/AP 及错向互补状态。重试概率应在这些条件下测得，再评估持续服务能力与尾延迟。
