# HfO₂ 二元1T1C FeRAM：保持读码的局部数字 CIM

[中文分析 PDF](output/feram_hfo2.pdf) · [章节 TeX](tex/08_feram_hfo2.tex) · [证据与桥接](notes/evidence.zh.md) · [输入](data/inputs.json) · [未取整结果](data/results.json)

主模式以 FERAM-03 的11 nm HZO、2.5 V、1T1C二元存储和破坏读恢复为实证基础，构造 K128×N128 INT8 的局部数字参考组织。32片×32行×128bit共131072个数据FeCAP，有效容量16 KiB；没有权重复制。4096 SA和恢复BL驱动、32个PL域并行读取恢复32条行，已有4096-bit单tile操作数跨八个输入bit使用；16数字通道、23-bit输出容器，完整向量需32次物理读和256轮计算。

外部更新为单域128bit接口和128个真实目标BL驱动，一条完整行16 Byte；1024笔行覆盖矩阵一次。内部恢复使用本地SA码，其4096路资源和外部目标写入分别列账。原文14 ns标为write latency，参考设计每极性保留14/50/100 ns，两相写、驱动边沿和控制完整计入；不会将原14 ns直接称为本组织完整更新。

| 情景 | ρ (MB/s) | τ (MB/s) | RI* | 完整装载 T_R (μs) |
|---|---:|---:|---:|---:|
| 短 | 69 | 310 | 0.22 | 53.248 |
| 典型 | 27 | 110 | 0.25 | 153.600 |
| 长 | 13 | 53 | 0.24 | 307.200 |

典型完整向量间隔4.810 μs，更新事务150 ns；未取整能力为26.6112266/106.6666667 MB/s，RI*=0.24948025。匹配本矩阵的 U*=T_R/Δ_S=31.9335=128·RI*。正常三情景保持组织、驱动数量及额定能力固定，读恢复与两相写共享相同极性窗口。固定其他条件的保持窗口、同硬件逐位重读对照在结果中单列。

驱动采用声明的250 fF/BL、2.5 V负载，固定80 μA/BL资格覆盖最短10 ns边沿所需62.5 μA。典型128路外部BL边沿需4 mA，4096路恢复需128 mA；PL极化负载另计。2Pr>40 μC/cm²与1 μm²cell仅给每条128-cell PL翻转电荷>51.2 pC，不能作为包含介电与布线电容的充分驱动额定。完整PL负载、并行恢复供电和短窗口状态资格是外部审阅重点。

操作数捕获已含于完整读窗口，八拍只读计算后覆盖；累加器另存，不与下一tile重叠。无免费全矩阵shadow、额外verify或周期刷新。真实破坏读恢复每次计入；raw/effective能力在活动服务维护假设下相同，寿命另列。
