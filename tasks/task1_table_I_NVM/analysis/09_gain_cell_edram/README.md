# Gain-cell eDRAM：同状态读写与刷新

当前统一入口：[十例复核](../TEN_CASE_REVIEW.zh.md) · [结果JSON](../data/ten_case_results.json) · [结果CSV](../data/ten_case_results.csv)。PDF首页结果卡与这些导出由统一适配器生成；本例原始未取整结果仍在 `data/results.json`。摘要统一十进制MB/s，情景分类见统一复核。


本轮保留有效参考计算，并将刷新临界压力与普通情景分开；统一当前结论见[十例集中复核](../TEN_CASE_REVIEW.zh.md)。

阅读入口：[独立中文 PDF](output/gain_cell_edram.pdf)；[中文章节](tex/09_gain_cell_edram.tex)，独立入口为 [gain_cell_edram.tex](tex/gain_cell_edram.tex)。

主模式选 GC-04 的 3T1C current-programmed 二进制端点 ±700 nA 伪差分 ACIM，以原 65 nm 器件/宏为依据接共同 28 nm 外围；不是已测 28 nm 宏。每 INT8 权重16cell、总262144cell，八平面并行，保留64行负载，每次16输出，128差分ADC/128真实pair写driver，一个更新域。

关键原文补充：GC-04 p.9–10/Fig.16 **实测完整65ns** 两步电流编程，包含5ns粗写；p.8/Fig.12的60ns另属仿真。0.4ms保持仅是99.7%测试cell漂移<1原ADC LSB，不是无错保证。采用端点符号判决避免把多级漂移直接四舍五入为原码；尾部、噪声、反复刷新裕量仍需验证。

摘要吞吐统一为十进制 MB/s（10^6 Byte/s）；矩阵容量为 16384 Byte = 16 KiB。原始服务占用与长期维护后能力分开：

| 类型/情景 | 无维护 C_S/C_R (ns) | 刷新 (µs/400µs) | 可用率 | ρ (MB/s) | τ (MB/s) | RI* |
|---|---:|---:|---:|---:|---:|---:|
| 普通短 | 14852 / 71 | 189.440 | 52.611% | 4.534 | 118.6 | 0.03824 |
| **推荐参考** | 23690 / 80 | 266.240 | 33.394% | 1.804 | 66.79 | 0.02702 |
| 临界压力：长 | 35860 / 105 | 384.000 | 3.930% | 0.1403 | 5.989 | 0.02342 |

可用率包含每周期 116/185/280 ns 的批边界禁发余量。普通条件情景范围仅含短/参考两点，不把长点当作代表性下界或完整物理不确定区间。长点固定其他参数时须满足 `1025 t_m + 179280 < 400000 ns`，即 `t_m < 215.337 ns`；把原 200 ns 增至 216 ns 时，维护加禁发已达 400.680 µs，α=−0.00170，该调度不可行。JSON 保留带符号 α，长期能力、有效间隔和 ridge 为 null；脚本同时检查 α=0，绝不裁正。

参考无维护能力为 5.403/200.0 MB/s；共同 α 虽在 ridge 中抵消，两路能力仍各损失 66.61%。每周期余 133.575 µs 可服务时间，相对 185 ns 不可中断组有明确调度余量，因此保留为本资源组织的条件代表点。C_A=T_I+t_m+T_A；t_m=100/150/200 ns 是工程预算，共享时隙真实传播，完整原 180 ns 宏不重复叠加。

参考手算：每16Byte写CR=3×5+65=80ns；每组刷新175+5+80=260ns，共1024组；α=1−(266240+185)/400000=0.3339375。ρ=128α/23690，τ=16α/80，RI*=(128/16)×80/23690。结果是固定全矩阵刷新策略的稳态平均，不是每请求latency或cold首次装载时间。新写不抵扣刷新是控制选择；允许抵扣时应重算。

仅保留一个资源对照：16→32输出组，同时ADC及pair driver翻倍，数字重构仍16通道，本地sign decoder随ADC翻倍。实际维护重新计数，参考ρ约提升3.7倍，而非只除以两倍求值轮数。GC-01/02/03/05作为机制与边界说明；没有混用GC02的5µs/99%作为精确保证，也没有将GC05 storage更新当作stationary提交。

```sh
GAIN_CELL_PYTHON=/opt/anaconda3/bin/python sh scripts/build.sh
/opt/anaconda3/bin/python scripts/render_pdf.py
```
