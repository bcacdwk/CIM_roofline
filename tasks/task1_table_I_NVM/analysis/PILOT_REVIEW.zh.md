# 首批三个案例的集中复核

2026-09-18。入口：[共享方法](shared_baseline/README.md)、[SRAM DCIM](02_sram_dcim/README.md)、[3D NAND](04_nand_3d/README.md)、[RRAM](05_rram/README.md)。

**结论：共享公式、参数与API不变，SRAM保持；NAND和RRAM已补成有限的条件工程估算。** 两个案例均明确了原始证据、跨实现可借用的操作、额外资源、成功终点和选定预算，并给出完整ρ／τ／RI*及组织对照。这里“数值估算完成”指选定参考设计的服务能力已有有限、可复算情景，不指原器件实测参数已被复原或已证明全部器件都满足预算。

## 一、对审阅问题的独立判断

**工程外推的标准此前偏严，需统一。** SRAM已经允许将48-bit、8T、1.05 V平台的完整同步周期锚点，结合共同节拍移植到128-bit、6T接口；未要求先完成目标实现的良率或固定0.9 V时序验证。对NAND/RRAM，缺少同芯片两路实测也不应自动排除参考估算。但原始数字的层级和终点仍须对应，不能把相对提速、单脉冲或外部测试等待直接冒充完整服务。

本次采用同一判断规则：先确定完整操作及资源，再选择有数量级锚点的服务预算；工程选择与测量分列，预算内通过声明终点才计完成payload。短/参考/长是三组成对运行情景，不是统计分位数，也不是材料固有上下界。

**两项主组织限制确属设计选择。** NAND的108次复制并非INT8逻辑或电流求和的必要条件；NAND-04 Fig.8已经研究无input decimal mapping的低电流情景。复制会提高信号、降低独立随机误差，却不能成为本逻辑任务的默认必需代价。RRAM逐cell编程及逐次占用公共SAR也非二状态的必要限制；RRAM-05有解耦memory感测，RRAM-06有每IO双组驱动、完成检测和组内同步推进的结构依据。因此选择c=1积分NAND和16-lane二状态写验RRAM作为主参考，原组织以同预算对照保留，而不是只删开销。

## 二、参考范围及主要决定因素

所有streaming事务仍为128 Byte输入、128×128 INT8矩阵和128×24-bit输出。SRAM精确整数、两种ACIM近似部分和的合同不变；未新增共同算法误差阈值。下表是内部数值汇总，不是最终Table I。

| 主情景 | ρ（MB/s） | τ（MB/s） | 成对RI* | 决定因素 |
|---|---:|---:|---:|---|
| SRAM DCIM：16项归约、16活动输出通道 | 24.9–58.0 | 1600–7270 | 0.00798–0.0156 | 512个完整MAC槽，独立128-bit同步写周期；保留原结果 |
| 3D NAND：c=1积分读出、单域同地址整矩阵重写 | 0.0751–0.0765 | 0.00135–0.00457 | 16.7–55.7 | 25µs积分、1024数据页、256校准页、128次块擦 |
| RRAM：32项求和、16-lane二状态RESET/SET写验 | 5.88–23.8 | 0.108–0.331 | 54.4–71.9 | 1µs脉冲、前后HV余量、组内尝试数及16路写资源 |

NAND预擦除append另得τ=0.00320–0.0123 MB/s、RI*=6.22–23.5，前提是数据页已擦除、参考页已建立，写后仍重算校准。该有限窗口不能替代持续重写。

### NAND：可借用什么，如何构造范围

- **读出**：NAND-05的2 nA名义电流及NAND-04的约16 pF原生SL负载提供锚点。主设计每页只用128个cell，保留原生13824 BL／32 WL／3 SSL几何；新增128路虚地积分前端，每路**另配**16 pF反馈电容，总2048 pF，采用0.4 V有用摆幅。`T_int=C_F·ΔV/(128·2 nA)=25µs`，不是把原max-bit时序直接搬给小电流。530/640/750 ns用作反馈前端建立预算，恢复另预留同长时隙；两者都是适配预算，普通存储t_R未被充当CIM周期。
- **编程与擦除**：NAND-01给出MLC program 1.3/2.5 ms（typ/max）、TLC maximum 5 ms，且MLC/TLC erase同为15/45 ms。借用的是完整高压、program/verify、erase/verify和恢复的操作量级，选择`P=1.3/2.5/5 ms`、`E=15/30/45 ms`；未迁移多级判决终点，未按小页或有效cell数量缩时，也不宣称这些是SLC测量界。所选两阈值状态工作于源文的饱和平台，不附加逐cell多级模拟电流精调。源产品floating-gate与SGVC的差异是明确的预算移植条件。
- **校准**：依据NAND-05 Fig.12，配置两个已知码WL，执行零点、满量程、半输入复测，共三读、两次WL设置和226个数字拍；计算有限校准时间，而非继续留无界C。每次求值增加一拍校正并配置128个小乘法器，资源与时间同步计入。半量程残差门槛四个逻辑计数是设计验收条件，不是所有输入误差保证。

P/E内未完成验证或校准失败时不发布矩阵、不计完成payload。这限定参考实现的工作条件；没有通过追加无限重试隐藏写成本。完整原值到预算桥接见[NAND证据表](04_nand_3d/notes/parameter_evidence.md)。

### RRAM：有限写序列与公平的校验比较

保留32项读结构和5ns前端锚点，主写通路改为八权重平面×两个列组，共16个独立编程lane。新增16个耐压限流驱动、32个binary窗口比较器、两个组地址计数器及mask/done状态；单更新域内并行，未从128-bit输入口推断并行度。

RRAM-05的典型10/100kΩ及变异模型支持选择LRS `[8,12] kΩ`、HRS `≥70 kΩ`的二目标验收窗。RRAM-01实际1µs SET/RESET脉冲作为跨stack波形锚点，前后各预留1µs HV建立/恢复；RRAM-02补充28nm可调编程电压的量级依据。该LRS导纳高于NeuRRAM的30/40µS目标，较宽窗口本身不能证明尝试更少，因此不移用其8.52次平均、56µs投影或99%成功率。

按RRAM-03的binary P&V和RRAM-06的分组完成策略，选择`(K_RESET,K_SET)=(1,1)/(2,1)/(4,2)`三种预算内达窗情景；它们是组内最慢活动cell的尝试数，不是实测分布。先RESET更新域、再masked SET，避免假定同一WL同时混合极性。每批在八平面各选两个列组的一个cell，8批覆盖128cell，即16个完整INT8权重。未通过的lane继续修正，超出情景预算不计为该情景成功。

binary比较/采样/锁存采用与共同完整转换能力一致的`T_B=10/20/50 ns`预算，另计选通、5ns建立及done提交。没有把NeuRRAM受外部DAC/ADC控制的1–10µs读回强加为本地SA延迟，也没有按位数把SAR周期削为零。电流预算0.30mA/lane、总4.8mA，以及最高1.8V专用写域，是必要资源条件而非原文动态电流/耐压测量。完整桥接见[RRAM证据表](05_rram/notes/parameter_evidence.zh.md)。

## 三、主Agent独立复算及策略代价

主Agent重新查看了NAND-04 Fig.7–9、NAND-05 Fig.6/12、NAND-01时序表，以及RRAM-03的raw/P&V原图、RRAM-06 Fig.1/3–10、RRAM-01 Methods与stack、RRAM-02 Fig.8、RRAM-05前端和状态参数。以下计算独立于案例与共享脚本执行。

**NAND参考点**（ns）：

```text
T_int = 16 pF × 0.4 V / 256 nA = 25000
ΔS = 8×303 + 64×(5+12+640+25000+640+20+3×5) + 2×5
   = 1687682 ns
C = 2×303 + 3×(5+12+640+25000+640+20) + 226×5 = 80687 ns
ΔR,rewrite = 1280×(110×5 + 2500000) + 128×30000000 + 80687
           = 7.040784687 s
```

`B_S=128 Byte，B_R=16384 Byte`，得到ρ=75.8437 kB/s、τ=2.32701 kB/s、RI*=32.5927。1280次program包括1024数据页和256参考页；后者只计成本，不加逻辑payload。每块八个有用数据页，不能用所有96个页位置摊薄erase。

唯一c=108对照采用**相同积分前端、完整写预算及校准规则**：参考ρ=1248.82 kB/s、τ≈2.32704 kB/s、RI*=536.66。复制使积分缩至231.48ns，读吞吐提升约16.47倍而非108倍，并要求每通道27.65µA输出驱动、1.73 V/µs压摆能力；总信号电流约3.54mA。独立随机cell误差约由1.70降至0.163计数LSB，二者不是等最终精度比较。因此主参考改为c=1并非挑更好看的吞吐，而是把复制从介质必需项还原为显式的信号、精度和资源选择。

**RRAM参考点**（ns）：

```text
ΔS = 256×(5+5+20+2×5)+2×5 = 10250
单尝试 = 1000(HV建立)+1000(pulse)+1000(恢复)+5+5+20+2×5 = 3040
ΔR = 2×5 + 8×(2+1)×3040 = 72970
```

`B_R=16 Byte`，得到ρ=12.4878 MB/s、τ=0.219268 MB/s、RI*=56.9522。24µs为脉冲预算、48µs为显式HV余量；约三分之二写时间来自所选余量，不能归为材料固有切换时间。

同预算改为单活动lane，完整写时长为1167.370µs，τ=0.013706 MB/s、RI*=911.12。单lane binary与单lane SAR均付相同30ns局部读回预算，时间相同；主点收益来自16路有成本的并行，而非删除校验开销。二状态SA是否可以更快不用于主结果。

SRAM参考点保持`ΔS=2570 ns、ΔR=5 ns、ρ=49.805 MB/s、τ=3200 MB/s、RI*=0.0155642`。三例resident事务语义仍须区分：SRAM/RRAM为16 Byte完整权重更新，可同比聚合为全矩阵；NAND取全矩阵替换以覆盖位平面和块擦维护，不能据该τ推断任意16-Byte局部更新。
