## 证据、主导因素与已解决问题

**SRAM ACIM。** 回查SACIM-03的128行9T1C、reset/evaluation/readout及100MHz原图，保留正文0.9V与结论1.2V差异。原4b宏改为独立位平面及共享SAR，10/20/50ns为合并前端预算，不伪称测得cell分项。完整INT8需要64次求值、64批转换、8192标量转换及128重构拍。普通写与已验收DCIM同样借CMOS-07同步完整周期和CMOS-03的6T成功终点，采用2.2/5/10ns，真实128写驱动，R4不重复加控制。参考前端和ADC各占39.9%；固定外围改变前端，ρ可变化+24.9%/−37.4%，配对ridge较窄并非普遍稳健。

**2D NOR。** 回查NOR-01 pp.85–86的100/120/130ns随机读完整周期，以及NOR-02 p.66的256-Byte页0.4/3ms、4KiB sector 45/400ms和BUSY终点。读采用4096个本地SA的明确扩展，不把16-bit封装接口当介质必需限制。提前修正了“32读片必须32个sector”的推断：主布局每sector含八个512-Byte读片，整矩阵64次program、4次erase；同样读资源下32独占sector的对照使τ下降7.13倍。参考写耗时87.55%来自擦除。NOR-04/05用于解释模拟电流求和与精调，未把binary页写等同连续模拟调谐。

**MRAM。** 回查MRAM-06 p.2和SI的实际写路：先两MTJ均P，再择一AP；每8-Byte组需128/64条活动支路。主审补齐了左右各64个绝对P/AP判决，不能只看差分输出而漏掉P/P、AP/AP。MRAM-03 Fig.21的20/30ns是完整access量级，30ns处是有限样本零错地板；不将其变成新实现的概率保证。主表从无上限重试期望改为56/95/130ns有限完整写验预算，另示一次整组重写180ns；参考两相磁写占60/95。SRAM、MRAM与FeFET的本地终验条件采用相同工程外推标准。

**PCM。** 回查PCM-03的8WL电压求值及完整access、PCM-01 Methods的32个实际IDAC、RESET125ns/700µA和SET250ns及50ns尾沿；SET总300ns为保守解释，总250ns另作8.6%时间敏感性。八行组产生1024轮，不能归为PCM材料必需。增加行/对角模式栅控mux、9等级电压译码和两批重新求值的终验，资源及时间均明列。主审纠正了将模拟小电导768ns读验强加给SLC的初稿：同一恒流/钳位电压前端必须覆盖q=0/1最弱码，主终验重用该前端与公共SAR；768ns保留为唯一组织对照，参考写侧慢3.57倍。主参考73.0%写时间来自完整SET/RESET波形。

**HfO₂ FeRAM。** 回查FERAM-03 Fig.8–11的8ns sense、14ns write和破坏读/writeback，FERAM-04 Fig.13的185ns完整tRC及预充期间恢复，未用PZT F-RAM替代。主路径是实测HZO存储机制加参考数字计算，32片×128bit完整行并行恢复；t_s/t_p/t_e分别记录，14ns原write不能冒称原文单相脉宽。D0一向量256次读、每cell八次恢复；已补当轮4096-bit读码保存，避免SA复位后丢码。参考恢复占43.46%。额外数字锁存跨八输入位复用的对照，ρ提高5.93倍，说明组织影响。C2FeRAM的非破坏读与浮置G节点漏电单独解释，没有凭“无读扰”认定零维护。

**Gain-cell eDRAM。** 回查GC-04 Fig.8、10–12、16–18：65ns不仅有仿真邻近量级，原文还实测了完整两步写；180ns原宏含5b SAR，不能直接替代共享转换器。主审将容易在读回刷新中累积错码的MLC方案收敛为±700nA二端点、每bit两个3T1C；原0.4ms的99.7%/<1原ADC-LSB统计不冒称全bit保证。1ns MAC与64ns单pair读采用等电荷积分，双支路各200fF、总51.2pF明确计资源；写时隔离新增读负载，维持约50fF写锚条件。每轮1024组完整读/译码/重写，参考266.24μs；固定400μs相位及185ns禁发余量给α=0.3339375，长情景α=0.0393。维护后的长期间隔与原始占用分别保存。32输出/双倍ADC和写驱动的唯一对照同时改变求值及刷新成本，未套原宏1.1%折扣。

**3D vertical FeFET。** 两篇VLSI均回查原图。主器件明确是2026 vertical AND，SL+O-poor的±2V/20ns及O-0.1s抗扰工艺作为相容参考条件，未与2025 NOR电压/速度拼成同一实测宏。四层仅分装容量；4096感测节点来自32横向读通路。多列掩码按四类cell逐项核对Vw、Vw/3、2Vw/3、0电场。100ns是依据RAWD<100ns选择的保守观察窗，已含最后退回，非测得必需等待；参考占写时间46.2%。16→128 cell写驱动对照需八倍驱动资源，τ提高6.65倍，不能归功于层数。

## 主 Agent 独立复算与横向口径

以下直接按阶段算术计算，未调用案例或共享服务函数；再与最终JSON交叉校验。时间统一为ns，B_S均为128 Byte，RI*均保留B_S/B_R。

| 参考情景 | 独立Δ_S | 独立Δ_R及B_R | RI* |
|---|---|---|---:|
| SRAM ACIM | `64(20+20+2×5)+10=3210` | `5`；16 Byte | 0.0124611 |
| NOR | `256(120+5)+10=32010` | `4×45e6+64×0.4e6+(64×18+4×2)×5=205605800`；16384 Byte | 50.1810 |
| MRAM | `256(5+5)+10=2570` | `10+2×30+5+2(5+5)=95`；8 Byte | 0.591440 |
| PCM | `1024(20+20+10)+10=51210` | `15+8[5+60+125+300+2(20+20+5)]=4655`；32 Byte | 0.363601 |
| HZO FeRAM | `256(20+50+40+5)+10=29450` | `10+40+2×50=150`；16 Byte | 0.0407470 |
| Gain-cell eDRAM | `C_S=128×175+258×5=23690`，`Δ_S=C_S/α` | `C_R=3×5+65=80`，`Δ_R=C_R/α`；16 Byte | 0.0270156 |
| Vertical FeFET | `256(40+5)+10=11530` | `10+8(30+40+100+40+5)=1730`；16 Byte | 1.20035 |

Gain-cell参考刷新独立计算为`1024(175+5+80)=266240ns`、`G=175+2×5=185ns`，`α=(400000−266240−185)/400000`；得到长期`Δ_S=70941.4ns`、`Δ_R=239.566ns`、ρ=1.80431MB/s、τ=66.7875MB/s。其固定全刷新策略不因用户新写而跳过维护，故同一α在ridge中抵消；这是所选调度的性质。每次刷新固定起点和固定顺序，在开始前禁发新批，避免等待引发的保持期限抖动；冷启动先建立有效状态与相位。

SRAM、MRAM、FeRAM和FeFET可按相应对齐原生事务同比聚合整矩阵；PCM的32-Byte事务为特定对角组，完整矩阵512组覆盖无重复；NOR本来就是整矩阵任意重写，不能将其τ直接用于任意小字更新。

各例共同字节/输出合同一致。内部位展开、互补编码、ADC、写验和恢复只改变占用，不增加同一次逻辑payload。数字R0一轮需要4096个并行bit结果，各例写清感测/bitcell资源；ACIM保留公共ADC/数字通道，再按实际行组与编码计数。与已验收SRAM DCIM的16项、512轮区别属于原生组织选择，没有为排序重调它。

完整周期采用R4覆盖规则；没有一例只算成功脉冲而另一例又重复计完整恢复。MRAM、PCM及FeFET仍是明确终态验收条件下的有限服务预算，不能外推为所有cell无失败的持续实测带宽；失败的时间和重做步骤不得删除。范围均为少量配对，不把独立端点包络或资源对照混入主范围，也不将读写配对抵消解释为材料稳健性。
