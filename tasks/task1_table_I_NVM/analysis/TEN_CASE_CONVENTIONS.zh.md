# 十例共同计量与资源政策

Table I 描述所选原生参考配置的两路逻辑服务能力。K、N及更新域由可计算映射确定；128×128与16 KiB只在相应配置或展示换算中使用。共同28 nm外围是参考条件，不表示介质工艺相同或等面积。

- 输入边界是本地完整向量寄存，B_S=K b_S；resident边界是对应更新形状进入可计算状态。输入寄存随K，结果寄存随N；INT8精确数字容器至少采用16+ceil(log₂K)位。位平面、互补、复制、恢复和写验进入资源/时间，不重复增加有效payload。
- 数字路径可使用单tile、至多4096-bit读码保持，跨输入位复用；通常至多32活动项、16输出通道。原生16项归约保留原时钟。SA带宽与保持容量分别列账；新增捕获按每组一数字拍，已含捕获不重复计费。保持生命周期覆盖本组求值且禁止提前覆盖；无免费全矩阵shadow。
- ACIM分别声明原生前端、活动行、位平面、ADC数量与精度、采样保持和数字重构；公共示例为8平面各16 ADC、16条两拍重构通道。更大原生阵列必须核查模拟动态范围与数字位宽，不能用免费全数字权重缓存替代模拟机制。
- 单外部更新域采用128-bit编码数据接口；可配置至多128个二元目标的局部驱动资格。实际并行受原生选通、独立驱动、写电流、耐压与负载约束，不能把接口位宽当真实编程并行。FeRAM/FeFET享有相同配置资格，偏置节点与恢复驱动另账；原生页/块、对角写等保持真实组织。
- 输入捕获与结果寄存提交各一数字拍，前提是上述本地并行寄存边界；若完整原生周期已包含，则不再追加。必要阶段顺序执行，只有具备资源、保持与依赖证明的流水才取服务间隔而非单次latency。
- 三个主情景为固定组织下相容的乐观、典型、悲观条件，主要扫描主导服务参数；不机械取中点。扩ADC/驱动/缓存、原生尺寸变更另列资源或组织对照。预擦除burst、维护临界与不可行点不进入普通三情景。
- 原始占用含必需恢复、终验与完整擦除摊销；周期维护另给长期有效能力。不可行点返回空值，不裁剪为正吞吐。寿命与耐久不混入瞬时τ。
- ρ=B_S/Δ_S；完整矩阵τ=KNb_R/T_R；RI*=ρ/τ；U*=T_R/Δ_S=(Nb_R/b_S)RI*。Table II阶段入口共享输入仅计一次；硬件映射引入的分时、重放、共享更新资源必须先重新确定T_R、Δ_S。宏级U*仅在两路同比例扩展时可沿用。
- 机器时间ns、容量Byte、汇总速率十进制MB/s，保存未取整结果；展示一般两位有效数字。16 KiB平均成本=16384/τ，必须标记为比例换算，不能当任意真实请求延迟。
- 原始实测/仿真、工程选择与推导分开保存，主要参数保留页码、图号、偏置及覆盖阶段。正文呈现完整当前模型，审阅历史只记在审阅入口。

共享方法为唯一公共API。案例作者只写获分配目录；公共数据、表图及来源登记由指定写入者维护。独立检查不得调用主计算函数作为预期答案，内部检查不等于用户验收。
