## NAND：双幅值存储与固定符号相位

将权重分成非负的正、负幅值，分别使用四个base-4 block组；输入绝对值的四个base-4切片按正、负符号mask各执行一次。两个输入相位固定执行，空mask不跳过；减法发生在数字域，没有ADC之前的大公共偏置。原生BL开关、SSL复制和各block独立SL支持该参考选通组织。

保留64个block、每块30个数据WL与2个参考WL、3个SSL、三BL复制、2 nA单位电流、16 pF原生SL、0–25 μA前端和名义10bit ADC。有效K=4608、N=240、容量1,105,920 Byte；正负幅值分存增加编码占用，物理阵列并未减半。

完整求值为960轮、61,440次转换。原64路仿射校准和16棵base-4合并树保留，增加8路正负减法、8路符号累加及相应中间保持，每轮四个数字拍。输入端计入4,608-bit符号保持、16路幅值编码和288拍处理。写入端计入单输出41,472-bit幅值/符号暂存及16条目/拍格式器；128bit页口的数据页实际利用48bit/拍，参考常量页仍为128bit/拍。

完整装载执行5,760个数据页和384个参考页program、64次block erase、69,120拍逻辑权重编码及必要SL校准：

`T_R = 5760(P+290 T_D) + 384(P+110 T_D) + 64E + 69120 T_D + C`。

典型Δ_S=674,860 ns，T_R=1,916,119,720 ns，ρ=6.8280828616 MB/s、τ=0.5771664414 MB/s、RI*=11.8303532091、U*=2839.2847702。ρ下降来自两个输入符号相位与数字服务；τ下降主要来自同一物理装载服务所承载的有效容量减半，并包括新的格式化时间。

同条件名义诊断中，零点积恢复为0，±4608重构为±4592，对称抵消恢复为0。孤立单位1仍可量化为0，小幅非对称点积2可重构为24。改善来自去除编码公共偏置，不是按向量调补偿常数，也不表示稀疏或近零输出具有统一精度保证。

原N480偏置编码以独立的`restricted_encoding`记录保留原配置、资源与诊断；`workload_mapping_eligibility=false`，不自动进入普通signed-INT8映射和正常参考点选择。新参考的资格表示所声明近似服务的结构性映射，不是任意workload准确度认证。

## 五个ACIM的共同名义检查

[共同脚本](shared_baseline/scripts/check_nominal_services.py)与[完整数据](shared_baseline/data/nominal_service_diagnostics.json)覆盖五例各15类确定性输入，包括零、小幅正负、抵消、大幅、孤立项和分组/尾边界。按各自原生K、活动行及编码执行，输出真值、重构、绝对残差、非零相对指标、裁剪及零/抵消的独立记录；名义码宽、ENOB尺度和最终容器分别声明。

| 案例 | 可检查层级 | 结果含义 |
|---|---|---|
| SRAM ACIM | 标定后整数部分和与数字重构 | 所测码级重构一致；未实例化新的SAR物理传递链 |
| NAND | 理想电流、ADC、参考校准及有限数字重构 | 公共偏置问题改善，仍报告稀疏/近零量化损失；保留同向量旧编码对照 |
| RRAM | 标定后整数部分和与数字重构 | 所测码级重构一致；不把跨实现电导窗假设当精度认证 |
| PCM | 标定后九级部分和解码与数字重构 | 所测码级重构一致；缺少新前端标定码表，未捏造非线性曲线 |
| GC-04 | 理想电流积分、10bit量化及有限数字重构 | 保留正端码饱和和舍入前残差；固定整数部分和舍入后所测向量一致 |

GC整数解码落在已有数字校正拍和容器内，不增加隐藏分数累加位，也不按正确答案修补输出。例如全1向量在舍入前为63.9375而非64，大幅向量为1031247.9375而非1032256；最终整数部分和重构不能用来声称前级量化没有误差。

前三个仅码级检查的案例明确`quantization_induced_bias_assessed=false`、模拟ADC链未实例化。代码/公式一致、名义诊断、模拟非理想性、实物验证和目标workload适用性分别记录；未设置统一网络准确率门槛或噪声分布。
