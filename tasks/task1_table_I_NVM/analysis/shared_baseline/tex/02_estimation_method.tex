\section{\texorpdfstring{局部 CIM 的 $\rho$、$\tau$、$\RI^*$ 通用估算方法}{局部 CIM 的两路服务估算}}

\subsection{服务粒度与 Table II 连接}

一次 streaming 服务完成 $B_S$ Byte 输入的规定求值及输出，一次 resident 服务使 $B_R$ Byte 逻辑状态可计算。对应服务间隔为 $\Delta_S,\Delta_R$：
\begin{equation}
\rho=B_S/\Delta_S,\qquad\tau=B_R/\Delta_R,\qquad
\RI^*=\frac{B_S}{B_R}\frac{\Delta_R}{\Delta_S}.
\label{eq:service}
\end{equation}
时间以秒代入得到 Byte/s；以 ns 代入 $B/\Delta$ 得到十进制 GB/s。内部位展开、互补编码、参考页、转换与 verify 只增加资源和时间，不重复增加同一次逻辑 payload。输出不加到 $Q_S$，但输出完成服务计入 $\Delta_S$。

Table II 在算子或矩阵阶段入口计数，同阶段共享源输入只计一次。对 $W[N,K]$ 完整装载一次、服务 $U$ 个向量，
\begin{equation}
\begin{aligned}
Q_S&=UKb_S,& Q_R&=KNb_R,& \RI&=\frac{Ub_S}{Nb_R},\\
\rho&=\frac{Kb_S}{\Delta_S},&\tau&=\frac{KNb_R}{T_R},&
U^*&=\frac{T_R}{\Delta_S}=\frac{Nb_R}{b_S}\RI^*.
\end{aligned}
\label{eq:mapping}
\end{equation}
INT8 两侧均为 1 Byte 时 $U^*=N\RI^*$。$T_R$ 必须是与该矩阵、更新模式和配置对应的完整装载，不能替换成任意小事务延迟。$\Delta_S$ 是完整向量的服务间隔，有流水时不直接取单次 latency。该平衡关系不保证共享两路同时达到峰值。

宏扩展到算子时，输入共享、重放、分时及共享更新资源可能分别改变 $T_R$、$\Delta_S$；只有二者同倍率扩展，宏级 $U^*$ 才可沿用。FFN、多分支和 Attention 仍按各阶段与实际映射连接。辅助展示每 16 KiB 平均更新成本为 $T_R(16384/(KNb_R))$，它不是一笔真实 16 KiB 请求的延迟。

\subsection{操作模式与参数依赖}

正常求值、写后终验、装载校准和恢复/刷新分别声明选通、偏置、负载、观察要求及建立终点。同一物理参数或明确关联的共同能力参数使用一个源值，绑定全部实际消费者；改变该值后重新计算所有相关阶段、完整 $T_R$ 和两表接口。$T_I$ 作用于实际输入形成与公共复位，$T_A$ 作用于使用转换时隙的求值或读验，$T_D$ 作用于捕获、重构、接口、比较及控制。某类数字感测按政策采用同一 $T_A$ 预算，并不意味着它与求值共享同一 ADC 电路。

完整前端 $F$ 已含 $T_I$ 时，以 $t_m=F-T_I$ 传入分项模板；固定 $F$ 只改变分解，固定 $t_m$ 则 $F$ 随 $T_I$ 改变，两种条件应明确区分。完整页 program 已含的内部 verify 或完整宏已含的捕获不重复收费。不同操作可以使用不同时间，但其偏置、观察终点或控制窗口必须确有区别。同一物理通路仅增加最低观察要求 $F_{\rm obs}$ 时，终验仍受共同建立时间约束，取 $F_V=\max(F_A,F_{\rm obs})$，同时绑定两个参数。只有不同实际路径或偏置具有对应证据和资格条件时，才可独立指定终验前端；仍然共用的转换和控制参数继续传播。单独延长终验的观察模式不能同时充当正常求值与终验共用前端较慢的不确定性包络；后者必须联动两路。

固定资源的主三情景、同模式参数敏感性、操作模式对照、资源对照和维护压力分别标记。维护前端或控制变化时，同时重新计算维护占用 $H$、非抢占 guard、可用率 $\alpha$ 及原始和有效能力，不只更新正常求值时间。机器接口采用参数到服务的有限映射并拒绝未知覆盖项；扰动检查还须核对实际阶段系数，不能把映射存在本身作为物理相容的证明。

\subsection{A. ACIM streaming：求值、转换和重构}

输入每片 $u$ bit、行组至多 $r$ 项、$W$ 个物理转换平面每次并行 $w$ 个，基础组合数
\[
F=\left\lceil8b_S/u\right\rceil\left\lceil K/r\right\rceil\left\lceil W/w\right\rceil.
\]
$W$ 由实际编码确定；多位状态可使其不同于 $8b_R$，必须证明状态可正确求值与重构。每组合输出分成求值组 $e_j$，$\sum_j e_j=N$；每平面 $a$ 个 ADC，各组按实际尾批 $o_{jb}\leq a$ 转换。$d$ 条数字输出通道，每重构轮 $k_A$ 拍，则
\begin{equation}
N_E=FJ,\quad N_C=F\sum_j\lceil e_j/a\rceil,\quad
N_{\rm rec}=F\sum_{j,b}\lceil o_{jb}/d\rceil,\quad N_{\rm dig}=k_A N_{\rm rec}.
\label{eq:acount}
\end{equation}
有用标量转换数为输入片数乘行组数乘 $WN$，尾部空槽不产生额外 payload。顺序服务为
\begin{equation}
\Delta_{S,A}=N_E(T_I+t_{m,A})+N_CT_A+N_{\rm dig}T_D+T_H+c_0T_D.
\label{eq:acim}
\end{equation}
$t_{m,A}$ 包含阵列响应、专用前端及必要恢复，$T_H$ 为额外模拟保持采集开销。若每组只求不超过 ADC 数的输出，转换后重建下一组，可令 $T_H=0$。若先求全组再分批读，须有至少 $\min(W,w)\max_j e_j$ 个有效模拟槽、隔离和缓冲；保持窗口覆盖该组全部转换与交错数字服务。等待已计在总时间，不另加一次保持时长。原生行数或输入位宽变化后，检查码范围、ENOB、符号和数字重构。

R0 的 $K=N=128,u=1,r=128,W=w=8,e=a=d=16,k_A=c_0=2$，得到 64 求值、64 转换批、128 数字拍和 8192 标量转换。$B_S=128$ Byte 仅属于该算例，不是 API 常数。

\subsection{B. DCIM streaming：读码保持与实际带宽}

每轮输入 $u_D$ bit、权重 $v_D$ bit、$r_D$ 项、$d_D$ 输出，计算轮数为
\begin{equation}
\begin{aligned}
N_D&=\lceil8b_S/u_D\rceil\lceil8b_R/v_D\rceil\lceil K/r_D\rceil\lceil N/d_D\rceil,\\
\Delta_{S,D}&=N_{\rm rd}t_{m,D}+N_Dk_DT_D+N_{\rm cap}T_D+T_L+c_0T_D.
\end{aligned}
\label{eq:dcim}
\end{equation}
对权重、行、输出的每个实际 tile，包含 $g_j$ bit，感测宽度为 $s$ bit/批。跨所有输入片保持时 $N_{\rm rd}=\sum_j\lceil g_j/s\rceil$；不保持则再乘输入片数。新增锁存的 $N_{\rm cap}=N_{\rm rd}$，已有静态连接或已覆盖 SA 捕获为零；$T_L$ 仅放入未覆盖的额外开销。保持容量不小于最大 $g_j$，同一 bank 完成本 tile 全部输入位后才能覆盖。破坏性读取及整行恢复按完整物理读批另算，不按只有用权重 bit 减去必需恢复。

R0 单 tile 为 $32\times16\times8=4096$ bit；256 轮计算、32 tile 读取。示意 $s=4096$ 时，每 tile 一批读取和一次捕获：$\Delta_S=32t_{m,D}+290T_D$。取 $t_{m,D}=10$ ns、$T_D=5$ ns，得到 1770 ns。若 $s=128$，每满 tile 要 32 批读取，不能仍使用 32 次感测。SRAM DCIM 的原生 16 项与静态连接可直接填入，既有保持不增加锁存成本。

服务模板默认串行。流水必须先证明各级资源、缓冲与依赖，再按每完整向量的资源占用求稳态间隔；同一硬件上的阶段先合计，有限窗口保留填充与排空。完整宏周期可覆盖读码、归约、捕获等，但应清楚标出替代范围。

\subsection{C. 直接更新：逻辑完成量、编码和尾批}

一次更新 $L_w$ 个完整权重，每权重 $c$ cell，一批实际完成 $p$ cell。仅当选通独立且分组对齐时，$n_w=\lceil L_wc/p\rceil$；受原生行/列限制则列实际批表。编码装入 $D_{\rm enc}$ bit，接口 $w_{\rm IO}$ bit，$n_b=\lceil D_{\rm enc}/w_{\rm IO}\rceil$：
\begin{equation}
B_R=L_wb_R,\qquad T_{\rm front}=(2+n_b-\chi)T_D,\qquad
\Delta_R=T_{\rm front}+\sum_{j=1}^{n_w}t_{{\rm update,full},j}.
\label{eq:direct}
\end{equation}
$\chi=1$ 表示首数据批随命令捕获。$p$ 由真实驱动和负载给出，不等于接口宽度。互补编码增加 cell 和装入量，不能增加 $B_R$。完整周期包含的控制、恢复、验证不重复收费。

完整矩阵装载应枚举实际事务和尾批：$T_R=\sum_j n_jt_j$、$KNb_R=\sum_jn_jB_{R,j}$。例如 35 Byte 矩阵以 16 Byte 事务更新，尾批仍用一个完整周期，必须按 $16+16+3$ Byte 和三次周期计；不能按 $35/16$ 次周期计算。

\subsection{D. 分步编程、原生页块与维护}

分步操作的完整时间为
\begin{equation}
\Delta_R=T_{\rm front}+T_{\rm pre}+\sum_j(T_{{\rm program},j}+T_{{\rm verify},j}+T_{{\rm recover},j})+T_{\rm erase,amort}.
\label{eq:program}
\end{equation}
RESET/SET、终验、偏置退出和恢复按实际机制保留；完整 program 已含 verify/retry 时只计一次。循环次数取自证据和终点条件，不凭空加入或消去重试。

一个完整持续块周期包含所有数据、参考、校准及必要复制页：
\begin{equation}
T_R=T_{\rm erase}+\sum_p(T_{{\rm front},p}+T_{{\rm program,full},p}),\qquad
B_R=\sum_pB_{{\rm logical},p},\qquad\tau=B_R/T_R.
\label{eq:page}
\end{equation}
参考页和增强信号的重复存储可取零新增逻辑字节，但仍付编程与物理装入成本。只有能在选定 CIM 路径中独立选通并完成求值的权重才算有效容量。均匀且完整利用的块可化成页 program 加 erase/有效页次数；预擦除 burst 必须标明有限窗口。示意 256 Byte 页、2048 bit 装入、10\,$\mu$s 完整 program、200\,$\mu$s erase/16 页，参考服务为 $90+10000+12500=22590$ ns。

周期 refresh 与破坏性读恢复是内部维护，$Q_R$ 不因此增加。若维护与两路服务确实共享同一串行资源，每周期 $T_M$ 预留维护 $H$ 和最大不可抢占批 guard $G$，则 $\alpha=1-(H+G)/T_M$，维护后 $\rho=\alpha\rho_0,\tau=\alpha\tau_0$。原始与有效能力分开保存；$\alpha\leq0$ 标记不可行，输出空有效时间和能力，不能裁成微小正数。此模型不自动提供流水、跨端口重叠或新写抵扣刷新；这些策略须以资源和依赖另行证明。正常悲观情景应仍有合理持续服务余量，维护临界点另列。
