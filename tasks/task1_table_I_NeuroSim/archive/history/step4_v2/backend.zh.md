# Step4 V2 后端时序资格

电路、22nm/LSTP/300K、10µm局部连线、DFF边界工程模型及类型适配继承[只读V1说明](../step4/backend.zh.md)。本轮没有改变介质参数、阵列组织、算术门图、负载、通道或保持资源。仍从锁定V1.4逐文件核对Git blob、新副本编译，实际执行DFF/Adder/SAR和formula；不是宏PPA或STA签核。

## PCM/GC保持窗口

E0是SAR完成后的第一个公共启动边沿，保守不借其前的组合传播。PCM阈值/选列、SAR码、输入位、输出组、旧累加器保持到E2；阈值稳定仍是未验证原生标定条件。GC输入向量/bit已用于前端积分，popcount从同一保持输入组合产生；将整个popcount/解码/重构图仍保守视作E0启动，没有popcount寄存器。E1只更新既有phase，不改变任何数据/组选择或累加值；E2才写回输出并释放SAR。完整数据图9.407240/10.500415ns分别获得两拍窗口，统一网格政策选择PCM5ns、GC5.5ns。

新明确的E1 phase→四级译码→有负载分发→已有捕获mux/setup路径为2.059456ns，保持单拍；普通controller/I/O/clear/verify/refresh-sign路径也保持单拍。没有把所有路径统一除二，没有新bank、流水或跨批重叠。机器快照保存每个路径的启动/捕获边沿及每个源的稳定窗口。

## 四个二元数字MAC的临界来源

在不删除门或电容的同一图上分离source arrival类别，所有类别最大值精确复现V1全图。输入数据及row/output group从native read开始保持，输入组mux至既有组合源pin已在读期间建立；这种源不在八个bit操作中每拍重新启动。每拍ibit/累加反馈和首拍新weight仍采用完整单拍路径，没有预选缓存。
