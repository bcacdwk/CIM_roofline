Generated request.h and Param constructor substitutions come only from that resolved package. Native automatic transistor resizing is disclosed. Resource counts, topology, interfaces, clock policy, precision and request overlap are held fixed per case. SAR delay retains its source formula and does not magically acquire thermal/PVT behavior.

Output register-ready and full matrix compute-ready are endpoints. Stable external rails exclude supply start-up but local switching and return are counted. rho=B_S/delta_S, tau=B_R/T_R, RI=rho/tau, U=T_R/delta_S=31RI. Separate model physical paths, reserved clock budget and cycle rounding. Unsupported/numerically invalid combinations must be explicitly excluded, never clamped into positive normal performance.
