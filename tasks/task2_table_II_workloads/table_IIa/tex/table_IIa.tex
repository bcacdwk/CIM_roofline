\section{对象与公式}
设权重矩阵 $W\in\mathbb R^{N\times K}$，其中 $N$ 为输出维度、$K$ 为输入维度。
权重完整装载一次后，累计服务 $U$ 个输入向量。
这里统一把 $U$ 称为\textbf{复用次数（reuse count）}，包含首次使用；
它可跨多个 batch 或请求累计，直到这份权重被替换或重新装载。

将这些向量按行记为 $X\in\mathbb R^{U\times K}$，则
$Y=XW^{\mathsf T}\in\mathbb R^{U\times N}$。
这只是累计计数的矩阵写法，不要求 $U$ 个向量同时组成一次 batch。
输入与权重均按每元素 1 Byte，在算子入口计入每个输入元素一次：
\[
\boxed{\displaystyle
\qs=UK,\qquad \qr=NK,\qquad
\RI=\frac{\qs}{\qr}=\frac{U}{N}.}
\]
$\qs$ 是累计 streaming 输入量，$\qr$ 是本窗口的累计权重写入量；
输出 $Y$ 不另加进 $\qs$。本表不需要任何硬件尺寸参数。

\section{结果说明}
固定 $N$ 时，RI 随 $U$ 线性增长；$U=1$ 时为 $1/N$。
$U\to\infty$ 是无界复用极限：$\qs$ 无界增长，而一次写入量 $\qr=NK$ 保持有限。
这里没有无穷大的实际 batch，也没有把有限窗口的写入量改成零。

相同 $N$ 的矩阵具有相同 RI：改变 $K$ 同时缩放输入量和权重写入量，比例中恰好抵消。
例如 $U=1\mathrm{K}$ 时，$1\mathrm{K}\times4\mathrm{K}$ 与 $4\mathrm{K}\times1\mathrm{K}$
两矩阵均写入 4 MiB 权重，输入分别为 4 MiB 与 1 MiB，RI 分别为 $1.0$ 与 $0.250$。
$1\,\mathrm{MiB}=2^{20}$ Byte。

后续 II(b) 沿用此记号与输入边界：同一矩阵阶段的共同源输入只计一次，
后续矩阵阶段的新输入另计。QKV 与 FFN 用 $U$ 表示权重复用次数；
Attention 用 $L$ 表示可见序列长度，并按其状态更新窗口累计。
