## 读数规则

- K 输出轴是 token，V 转置输出轴是 d，因此 tile 变化对 QK 和 AV 输入影响不同。
- INT8 输入固定时，INT4 权重对照只将 resident bytes 减半，RI 倍增。
- 7 份 KV copy 保留原有 query 总工作，写入与容量同时乘 7。
- dW alternative 的输出是 dW 转置，归置后的数学梯度相同；其临时 resident 和 streaming 角色交换。
- cycle 行是完整周期，dW 行是一 microbatch 的分项；不能同时相加。
