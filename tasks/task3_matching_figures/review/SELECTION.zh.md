# 两图组合建议

这是候选比较建议，最终由用户观看实际图后选择至多两张。五张图具有不同分析目标，颜色或轴变换本身不作为独立价值。

## 最直观的一组：A＋C

**A 给位置，C 给次数。** A 延续 Task I 能力平面的阅读方式，保留十类硬件两路能力和成对情景；C 把同一平衡关系译为可直接理解的“每次装载至少复用多少个向量”。两图使用相同 U、颜色、情景与方向判定，读者容易从能力比值过渡到工作负载复用要求。

推荐理由是实际图面的可读性与连续的解释路径。A 的圆与斜线可以展示相邻情景，C 则使 MRAM U=128 和 NOR U=128K 这类典型点不足以代表全组的现象一目了然。

代价是两图部分信息重叠，且没有 B 的真实模型绝对 Byte。A 的纵轴已变为 Nρ，必须保留准确轴名及 caption 中的坐标解释。组合适合论文先说明统一方法，再由表格或正文介绍模型需求。

## 设计启示最强的一组：C＋E

**C 说明需要多少复用，E 说明能力该向哪一路调整。** C 给出十类原生服务的阈值全景；E 从其中选取三个具体参考工况，显示非瓶颈通路改善、瓶颈通路改善及跨界后的收益饱和。

这里允许 C 替代保底图 A：若 Task I 表仍保留 ρ、τ 和原生配置，第二次展示能力平面不是必须的。把版面用于 E，可以增加“同一硬件在不同 U 下，改进方向如何改变”的独立信息。特别是 MRAM U=128 与 U=1K 的并列，避免把改进方向固定归因于介质名称。

代价是该组合不展示绝对需求和完整能力平面；若主文最希望突出具体模型映射，应优先重新比较 B。C/E 都不能被写成实测速度、能效或产品优劣结论；E 的倍数也不表示等工程成本。

## 其余候选的保留价值

| 图 | 最值得保留的信息 | 当前取舍 |
|---|---|---|
| A | 十类能力位置、原有风格、情景与复用线 | 直观组合的入口；设计组合可由 C 替代 |
| B | 真实 QKV 绝对 Byte、共享输入与显式重放映射 | 模型连接最强，但正文需容纳分块服务推导 |
| C | U* 的直接含义及三情景跨界 | 两个推荐组合的共同锚点，原因是读图清楚 |
| D | 距离各自 streaming 上界还有多远、何时饱和 | 教学解释好；与 C 的信息重合多于 E |
| E | 通路改善方向及收益上限 | 设计讨论最强；保留“解析参考上界”措辞 |

五张均按 7.16 in 双栏尺寸检查。A/B/C/E 高度约 4 in，D 为 2.60 in；用户定稿后可进一步压缩标题和说明，但本轮没有为缩版面省略关键状态、移动数据点或更改计量条件。
